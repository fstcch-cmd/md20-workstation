# 離線 3D viewer 與互作標示

狀態：**[已實作]**（pure 測試 + 容器內 headless Chromium 實際繪圖、無 JS 錯誤）。

- 自寫 Canvas 2D（`md20/gui/static/md20view.js`），無 CDN、無 WebGL；可從 file:// 開、嵌入報告。
- 場景：配體球棍、口袋殘基（配體 6 Å 內）重原子、Cα 骨架、金屬；水與離子省略；可播放 production 軌跡（≤ 60 幀）。
- 互作（`views.ligand_interactions`，逐幀、純距離準則，教學用、不是能量分解）：
  - 氫鍵候選：配體 N/O 與口袋 N/O ≤ 3.5 Å（H 已省略，**未檢查角度**）；
  - 疏水接觸：配體 C 與疏水殘基側鏈 C ≤ 4.0 Å（每殘基每幀取最近一對）；
  - 金屬配位：配體 N/O/S 與金屬 ≤ 2.8 Å。
  虛線：黃＝氫鍵、灰＝疏水、紫＝金屬；下方表格列出各殘基互作在軌跡中的佔有率。
- 「表面」：口袋原子 vdW 球（半透明，疏水殘基黃、極性藍）——**不是**溶劑可及表面，畫面與報告都寫明。
