# 報告用語規範：每張圖的通用說明（D-54）

使用者（11/02 15:53）：報告要有圖表，每一張圖表都要有專案等級的說明；先建立**通用用語**，列出幾種可能，產出的報告才順。**要通則，不是個案。**

本檔是規範，程式 `md20/report/figure_text.py` 逐條實作；改用語先改這裡，再改程式，測試檢查兩者一致（每個情境都有中英文句型、門檻寫在句子裡）。

## 一、每張圖的固定結構

每張圖在報告中都依同一順序呈現：

1. **圖與圖說**：「圖 n. 標題」＋一句說明圖上畫了什麼（軸、顏色、標記）。
2. **怎麼讀這張圖**：通用的判讀原則，不含本次數值；同一種圖在任何專案都相同。
3. **本專案的結果**：依數據自動判斷屬於哪一種情境，套用該情境的句型並填入數值。可同時成立多個情境（例如「已平衡」與「複合物比蛋白單獨穩定」）。
4. 最後一句說明**對結論的意義**（這個結果支持或不支持什麼）。

用語原則：主詞是數據不是程式（「主鏈 RMSD 在後半段維持在 1.4 ± 0.1 Å」，不寫「系統判斷」）；門檻寫進句子；不用「顯著」除非有統計檢定；
不確定時寫「不足以判斷」並說缺什麼；單位一律 SI 與 kcal mol⁻¹ 並列（自由能）；不用斜線作分隔。

## 二、圖的種類與情境

### F1 對接姿勢分數（每個配體一張長條圖；`docking_scores`）
- 圖：每個姿勢的 Vina 分數，依名次排列；顏色代表叢集，★ 為選用姿勢。
- 怎麼讀：分數越負越好；兩個分數相差小於 1 kcal mol⁻¹ 時在 Vina 誤差內，不能區分；同一叢集出現多個低分姿勢，表示搜尋收斂到同一結合模式。
- 情境：
  - **明確最佳**（第 1、2 名差 ≥ 1 kcal mol⁻¹ 且選用叢集占 ≥ 30 %）：最佳姿勢明顯優於其他，且在多次搜尋中重複出現。
  - **分數相近**（差 < 1）：數個姿勢在誤差內等價，結合模式不能只由分數決定，需以模擬穩定性判斷。
  - **搜尋未收斂**（選用叢集 < 30 %）：低分姿勢分散在不同叢集，建議提高搜尋強度或縮小搜尋區。
  - **重新對接成功或失敗**（有共結晶參考時，RMSD ≤ 2 Å 或 > 2 Å）。

### F2 篩選排名（長條圖；`screen_ranking`）
- 圖：化合物依分數排序；灰色帶為與最佳差 1 kcal mol⁻¹ 內。
- 怎麼讀：灰色帶內的化合物彼此不能排序；分數易受分子大小影響，應同時看配體效率。
- 情境：**明確領先**（第 1 名領先 ≥ 1）、**緊密群組**（≥ 3 個在灰色帶內）、**排名受分子大小主導**（分數與重原子數相關係數 ≤ −0.6）。

### F3 主鏈 RMSD 時間序列（各系統疊圖；`rmsd`）
- 圖：主鏈原子相對於起始結構的 RMSD 隨時間變化；每條線一個系統。
- 怎麼讀：曲線先上升後進入平台，代表結構已平衡；平台高度反映構形調整幅度（< 2 Å 小、2 到 3 Å 中、> 3 Å 大）；後半段仍持續上升代表尚未平衡。
- 情境（每個系統）：**穩定平台**、**調整後平台**、**持續漂移**（後半段漂移 > 0.5 Å）、**大幅重排**（> 3 Å）。
- 比較情境：**複合物較穩定**（比蛋白單獨低 ≥ 0.3 Å）、**複合物較擾動**（高 ≥ 0.3 Å）、**兩者相當**。

### F4 迴轉半徑（`rg`）
- 圖：蛋白迴轉半徑隨時間變化。
- 怎麼讀：數值穩定代表蛋白維持緊密摺疊；持續增加代表部分展開。
- 情境：**緊密穩定**（後半段變異 < 2 %）、**輕微擴張**（後半段平均比前 10 % 高 2 到 5 %）、**明顯擴張**（> 5 %）。

### F5 配體在口袋中的位移（每個配體；`ligand_rmsd`）
- 圖：以蛋白口袋對齊後，配體相對於對接姿勢的 RMSD；虛線為 3 Å。
- 怎麼讀：低於 2 Å 代表維持對接姿勢；2 到 3 Å 為姿勢調整；持續高於 3 Å 代表離開原結合位。短暫超過 3 Å 後回來屬於擺動。
- 情境：**維持姿勢**、**姿勢調整**、**短暫偏離後回到口袋**（最大值 > 3 Å 但最後 20 % < 2 Å）、**離開口袋**（並報告首次持續超過 3 Å 的時間）。

### F6 殘基柔性 RMSF（蛋白單獨與複合物疊圖；`rmsf`）
- 圖：每個殘基 Cα 的均方根擾動；下方為兩者差值。
- 怎麼讀：峰值通常是 loop 與末端；結合後下降的區域多半是結合位或與之耦合的區域。
- 情境：**結合位變硬**（列出下降最多的殘基）、**柔性整體相當**、**整體變軟**（平均高 ≥ 0.2 Å）。

### F7 接觸頻率（每個配體；`contacts`）
- 圖：與配體距離 < 4 Å 的時間比例，依頻率排序。
- 怎麼讀：≥ 75 % 為持續接觸（結合的錨點）；25 % 到 75 % 為間歇；< 25 % 為偶發。
- 情境：**有穩定錨點**（≥ 3 個殘基 ≥ 75 %）、**錨點少**（1 到 2 個）、**接觸鬆散**（最高 < 50 %）。

### F8 導向分子動力學的拉力與功（`smd`）
- 圖：拉力與累積功對彈簧位置作圖。
- 怎麼讀：最大拉力對應主要的斷裂事件；功在末段趨平代表配體已完全脫離；功與拉速有關，不是自由能。
- 情境：**單一斷裂峰**、**多階段脫離**（≥ 2 個明顯峰）、**已完全脫離**（末 20 % 功的增加 < 5 %）、**未完全脫離**（建議加長拉離距離）。

### F9 傘狀採樣窗口分佈（`umbrella`）
- 圖：每個窗口沿反應座標的取樣分佈。
- 怎麼讀：相鄰分佈必須重疊，自由能剖面才能連續；出現空隙的位置剖面不可信。
- 情境：**覆蓋完整**、**有空隙**（列出位置）。

### F10 自由能剖面（PMF；`pmf`）
- 圖：自由能隨配體與口袋距離的變化，陰影為自助法誤差。
- 怎麼讀：最低點為結合狀態，最低點到末端平台的高度為 ΔPMF；末端須平坦，否則 ΔPMF 被低估。
- 情境：**井深合理且末端平坦**、**末端未平**（末 0.2 nm 斜率 > 2 kJ mol⁻¹ nm⁻¹）、**井深不合理**（> 80 kJ mol⁻¹）、**誤差大**（誤差 > 井深的 20 %）。
