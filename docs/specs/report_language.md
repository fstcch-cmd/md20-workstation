## 一、每張圖的固定結構

每張圖在報告中都依同一順序呈現：

1. **圖與圖說**：「圖 n. 標題」＋一句說明圖上畫了什麼（軸、顏色、標記）。
2. **怎麼讀這張圖**：通用的判讀原則，不含本次數值；同一種圖在任何專案都相同。
3. **本專案的結果**：依數據自動判斷屬於哪一種情境，套用該情境的句型並填入數值。可同時成立多個情境（例如「已平衡」與「複合物比蛋白單獨穩定」）。
4. 最後一句說明**對結論的意義**（這個結果支持或不支持什麼）。

用語原則：主詞是數據不是程式（「主鏈 RMSD 在後半段維持在 1.4 ± 0.1 Å」，不寫「系統判斷」）；門檻寫進句子；不用「顯著」除非有統計檢定；
不確定時寫「不足以判斷」並說缺什麼；單位一律 SI 與 kcal mol⁻¹ 並列（自由能）；不用斜線作分隔。

## 二、圖的種類與情境

### F1 對接姿勢分數（每個配體一張長條圖；`docking_scores`）
- 圖：每個姿勢的 Vina 分數依名次排列。顏色代表叢集，★ 是選用的姿勢。
- 怎麼讀：分數越負越好。兩個分數相差不到 1 kcal mol⁻¹ 時落在 Vina 的誤差內，無法區分。同一叢集裡有好幾個低分姿勢，表示搜尋收斂到同一種結合模式。
- 情境：
  - **明確最佳**（第 1、2 名差 ≥ 1 kcal mol⁻¹ 且選用叢集占 ≥ 30 %）：最佳姿勢明顯優於其他，且在多次搜尋中重複出現。
  - **分數相近**（差 < 1）：數個姿勢在誤差內等價，結合模式不能只由分數決定，需以模擬穩定性判斷。
  - **搜尋未收斂**（選用叢集 < 30 %）：低分姿勢分散在不同叢集，建議提高搜尋強度或縮小搜尋區。
  - **重新對接成功或失敗**（有共結晶參考時，RMSD ≤ 2 Å 或 > 2 Å）。

### F2 篩選排名（長條圖；`screen_ranking`）
- 圖：化合物依 Vina 分數排序。灰色帶是與最佳分數相差 1 kcal mol⁻¹ 以內的範圍。
- 怎麼讀：灰色帶內的化合物彼此排不出先後。分子越大，分數往往越負，所以要同時看配體效率，也就是每個重原子的分數。
- 情境：**明確領先**（第 1 名領先 ≥ 1）、**緊密群組**（≥ 3 個在灰色帶內）、**排名受分子大小主導**（分數與重原子數相關係數 ≤ −0.6）。

### F3 主鏈 RMSD 時間序列（各系統疊圖；`rmsd`）
- 圖：主鏈原子相對於起始結構的均方根偏差隨時間的變化，每條線是一個系統。
- 怎麼讀：曲線先上升再進入平台，代表結構已經平衡。平台高度反映構形調整的幅度，小於 2 Å 算小，2 到 3 Å 中等，大於 3 Å 大。後半段還在上升，就是尚未平衡。
- 情境（每個系統）：**穩定平台**、**調整後平台**、**持續漂移**（後半段漂移 > 0.5 Å）、**大幅重排**（> 3 Å）。
- 比較情境：**複合物較穩定**（比蛋白單獨低 ≥ 0.3 Å）、**複合物較擾動**（高 ≥ 0.3 Å）、**兩者相當**。

### F4 迴轉半徑（`rg`）
- 圖：蛋白迴轉半徑隨時間的變化。
- 怎麼讀：數值穩定代表蛋白維持緊密摺疊，持續增加代表部分展開。
- 情境：**緊密穩定**（後半段變異 < 2 %）、**輕微擴張**（後半段平均比前 10 % 高 2 到 5 %）、**明顯擴張**（> 5 %）。

### F5 配體在口袋中的位移（每個配體；`ligand_rmsd`）
- 圖：以蛋白口袋對齊後，配體相對於對接姿勢的 RMSD。虛線是 3 Å。
- 怎麼讀：低於 2 Å 代表維持對接姿勢，2 到 3 Å 是姿勢調整，持續高於 3 Å 代表配體離開了原本的結合位。短暫超過 3 Å 又回來屬於擺動，不代表解離。
- 情境：**維持姿勢**、**姿勢調整**、**短暫偏離後回到口袋**（最大值 > 3 Å 但最後 20 % < 2 Å）、**離開口袋**（並報告首次持續超過 3 Å 的時間）。

### F6 殘基柔性 RMSF（蛋白單獨與複合物疊圖；`rmsf`）
- 圖：每個殘基 Cα 原子的均方根擾動。多個系統疊在一起畫，下方是複合物減去蛋白單獨的差值。
- 怎麼讀：峰值通常出現在 loop 與末端。結合後柔性下降的區域多半就是結合位，或與結合位耦合。柔性上升的區域則受到結合的擾動。
- 情境：**結合位變硬**（列出下降最多的殘基）、**柔性整體相當**、**整體變軟**（平均高 ≥ 0.2 Å）。

### F7 接觸頻率（每個配體；`contacts`）
- 圖：模擬時間中每個殘基與配體距離小於 4 Å 的時間比例，依頻率排序。
- 怎麼讀：75 % 以上是持續接觸，也就是結合的錨點。25 % 到 75 % 是間歇接觸，低於 25 % 是偶發接觸。
- 情境：**有穩定錨點**（≥ 3 個殘基 ≥ 75 %）、**錨點少**（1 到 2 個）、**接觸鬆散**（最高 < 50 %）。

### F8 導向分子動力學的拉力與功（`smd`）
- 圖：拉力與累積功對彈簧位置作圖。
- 怎麼讀：最大拉力對應主要的斷裂事件。功在末段變平，表示配體已完全脫離。功和拉速有關，它不是自由能。
- 情境：**單一斷裂峰**、**多階段脫離**（≥ 2 個明顯峰）、**已完全脫離**（末 20 % 功的增加 < 5 %）、**未完全脫離**（建議加長拉離距離）。

### F9 傘狀採樣窗口分佈（`umbrella`）
- 圖：每個窗口沿反應座標的取樣分佈。
- 怎麼讀：相鄰的分佈必須互相重疊，自由能剖面才會連續。出現空隙的位置，剖面不可信。
- 情境：**覆蓋完整**、**有空隙**（列出位置）。

### F10 自由能剖面（PMF；`pmf`）
- 圖：自由能隨配體與口袋距離的變化，陰影是自助法（bootstrap）誤差。
- 怎麼讀：最低點是結合狀態，從最低點到末端平台的高度就是 ΔPMF。末端必須平坦，否則 ΔPMF 會被低估。
- 情境：**井深合理且末端平坦**、**末端未平**（末 0.2 nm 斜率 > 2 kJ mol⁻¹ nm⁻¹）、**井深不合理**（> 80 kJ mol⁻¹）、**誤差大**（誤差 > 井深的 20 %）。


### 擴充圖（D-58，使用者 11/02 16:51：目前能力可做到的所有圖表都要進結案報告與系統，中英文版都要）
每種圖同樣有「圖說、如何判讀、本專案的結果」，情境門檻如下（句型見 `md20/report/figure_text.py`）。

**平衡與品質**
- F11 能量最小化（`minimization`）：位能下降量；最後一階段仍占總下降 30 % 以上 → 釋放約束後仍有可觀鬆弛。
- F12 平衡過程品質（`equil_quality`）：各階段溫度、位能、密度、盒體積；依驗收結果：全部通過 → 平衡完成；任一未通過 → 列出並提醒保守看待。
- F13 獨立重複（`replicas`）：各重複的溫度與位能疊圖。

**蛋白的穩定性與動態**
- F14 蛋白溶劑可及面積（`protein_sasa`）：後半段相對開始增加 > 5 % → 可能部分展開；否則穩定。
- F15 蛋白內部氫鍵（`hbond_protein`）：下降 > 10 % → 結構鬆散；否則穩定。
- F16 二級結構（`dssp`）：螺旋或摺板比例下降超過 5 個百分點 → 局部展開；否則保持。
- F17 動態交互相關（`dccm`）：相隔 5 個殘基以上的強相關（|r| > 0.6）比例；與蛋白單獨相比平均 |r| 變化 ≥ 0.05 → 配體改變區域間協同運動。
- F18 構形自由能地形（`pca_landscape`）：前兩主成分解釋比例；低谷（< 2 kT 的局部最小）1 個 → 單一構形；≥ 2 個 → 多個狀態。
- F19 構形叢集（`clusters`）：2 Å 門檻；最大叢集 ≥ 60 % → 主導構形；否則結合模式變動，比較代表結構。
- F19a 慢運動自由能地形（`tica_landscape`，D-105）：Cα 先 PCA 再 tICA（延遲為候選延遲的中位數）；低谷 1 個 → 單一慢狀態；≥ 2 個 → 慢速轉換的狀態，轉換次數少時相對深度不可信。
- F19b 隱含時間尺度（`msm_its`，D-105）：k-means 微狀態、對稱化計數；資格三級——insufficient（轉換 < 每狀態 10 次或連通 < 90%：只示範方法）、unresolved（最慢過程 > 模擬三分之一：不可當速率）、exploratory（曲線變平與否照實寫）；單一軌跡永遠不報速率。
- 表：持續的側鏈氫鍵（`hbonds_protein.network`，佔幀 ≥ 30%，排除純骨架氫鍵），附連結最多的殘基；配體 1 nm 內水合位點（密度 ≥ 2× 體相、佔有率）；軌跡只存溶質時明說「無法分析」。

**配體在模擬中的結合**
- F20 配體與口袋質心距離（`com_distance`）：後半段比開始增加 > 2 Å → 正在離開；否則留在原位（同圖下方為極性接觸數）。
- F21 配體埋藏程度（`ligand_burial`）：後半段平均 ≥ 70 % 深埋；40 % 到 70 % 部分埋藏；< 40 % 表面結合。
- F22 配體與蛋白的氫鍵數（`hbond_count`）：後半段平均 ≥ 2 → 極性作用為錨點；0.5 到 2 → 有貢獻；< 0.5 → 主要靠疏水與凡得瓦；比開始少 ≥ 1 → 極性作用喪失。
- F23 氫鍵佔有率（`hbond_occupancy`）：≥ 50 % 為穩定氫鍵（列出）；沒有 → 間歇。
- F24 作用指紋（`fingerprint`）：任一類型 ≥ 50 % 的殘基列為持續作用；沒有 → 結合鬆散。
- F25 水橋（`water_bridges`）：平均 ≥ 1 → 水參與結合（列出 ≥ 30 % 的殘基）；否則直接接觸為主。

**結合自由能品質**
- F26 窗口重疊矩陣（`overlap_matrix`）：相鄰最低重疊 ≥ 0.2 連續；0.05 到 0.2 連通但誤差大；< 0.05 斷開需補窗。
- F27 自由能剖面的收斂（`pmf_convergence`）：75 % 到全部取樣井深變化 ≤ 2 kJ mol⁻¹ → 收斂；否則需更長窗口。

**化合物與對接**
- F28 篩選分數分佈（`screen_hist`）：平均 ± 標準差；比平均好一個標準差以上的化合物列出。
- F29 分數與分子大小（`screen_scatter`）：相關係數 ≤ −0.6 → 排名受大小主導；否則不受主導。
- F30 化合物性質分佈（`properties`）：完全符合 Lipinski 的比例、違反兩項以上的數目（經驗規則，不作排除）。
- F31 化學空間（`chem_space`）：前 20 % 高分化合物彼此距離 < 整體平均的 60 % → 某結構類型有利；否則多種骨架。
- F32 二維作用圖（`interaction_2d`）：選用姿勢每個原子最近的殘基與作用類型（氫鍵 ≤ 3.5 Å、離子 ≤ 4 Å、疏水 C–C），列出各類型的殘基。

**分子對接的延伸分析（D-59，使用者 11/02 17:24：分子對接層面也要多產生圖）**
- F33 姿勢相似度矩陣（`pose_rmsd`）：前 3 名姿勢彼此平均 RMSD ≤ 2 Å → 收斂到同一結合模式；否則相近分數對應不同模式。
- F34 對接漏斗（`funnel`，有共結晶參考時）：最佳分數姿勢 ≤ 2 Å 且分數與 RMSD 正相關（r > 0.3）→ 評分函數辨認正確；最佳 ≤ 2 Å 但相關弱 → 區辨力有限；最佳 > 2 Å → 偏好錯誤模式。
- F35 姿勢在搜尋區中的位置（`pose_positions`）：三種情境 — 姿勢中心平均離散 ≤ 3 Å → 單一口袋（good）；≥ 60 % 姿勢在第 1 名 4 Å 內 → 主要位置＋分數較差的替代位置（note）；否則 → 數個競爭位置，對接分數無法決定（warn，建議 MD 比較或縮小搜尋區）。（模板首跑發現 4.4 Å 的單一口袋被誤判成多位置，改為以第 1 名為基準。）
- F36 各姿勢的接觸殘基（`pose_contacts`）：被 ≥ 70 % 姿勢接觸的殘基列為結合位核心；沒有 → 姿勢不共享結合位。
- F37 配體比較（`ligand_compare`，兩個以上配體）：最佳分數與最佳配體效率；前兩名差 < 1 kcal mol⁻¹ → 不能排序。

### 多配體同時對接與多配體系統（D-60）
同時對接時，對接一節改以「配體的排列」為主角：每個配體各畫一套單配體圖會讓版面隨配體數倍增，而且回答錯問題。
聯合姿勢的相似度矩陣（F33）與漏斗（F34）用全部配體的座標串接計算；單配體的位置圖（F35）與接觸殘基圖（F36）由下列取代。
姿勢表格的「接觸殘基數」改為每個配體分列，並加「配體間最短距離」欄；表格之後是幾何檢查表（每個配體：蛋白接觸、原子重疊、穿環、漂浮、處置）。
- F38 聯合姿勢的共同佔位檢查（`joint_poses`）：≥ 1/3 的姿勢同時共同佔位（配體間 3.3–4.5 Å）且每個配體都埋入 → good；有但少於 1/3 → note（共同佔位是待驗證的假說）；
  沒有 → warn（口袋可能容不下全部配體）；有碰撞名次 → note 列出；兩個以上同號帶電配體 → caution（Vina 沒有靜電項）。
- F39 各配體在搜尋區中的位置（`joint_positions`）：配體在某名次落到另一配體第 1 名位置（< 2 Å）→ caution（互換位置，誰佔哪個子位點無法由對接決定）；
  某配體中心離散 > 3 Å → note；否則 good（排列一致）。
- F40 子位點地圖（`subsites`，採用的聯合姿勢）：≥ 3 個殘基同時接觸兩個以上配體 → note（共用子位點，可能競爭）；1–2 個 → good（相鄰的不同子位點）；
  0 → good（完全分開）；某配體自己的接觸殘基 < 4 → caution（主要靠其他配體固定，模擬中較可能離開）。
- F41 配體之間的距離（`ll_distance`，多配體 MD）：前 10 % 與後 20 % 的平均差 ≤ 2 Å → good（共同佔位維持）；2–5 Å → note（重新排列仍相鄰）；
  > 5 Å → warn（共同佔位沒有維持，聯合姿勢不被模擬支持）。
  有平底限制（多配體系統預設）時加 caution：完全離開被限制擋住，「維持」不能當作自發穩定的證據。
- F42 協同自由能（`cooperativity`，熱力學循環，D-61）：先看循環閉合（兩路徑的差 ≤ 2σ；無誤差時 ≤ 4 kJ/mol）——不閉合 → warn（採樣未收斂，不報協同）；
  閉合且 |ΔΔG_coop| < 2σ → good（無可偵測協同）；≥ 2σ → note（負值正協同、正值互斥）；缺誤差 → caution（只給方向）；三個以上配體 → note（無成對循環，只列各配體位移）。

**結構預測**
- F43 逐殘基可信度（`fold_plddt`）：平均 ≥ 70 good；50–70 note（MD 檢查，RMSD 很快 > 3 Å 代表不穩定）；< 50 caution；列出 < 50 的殘基；ipTM ≥ 0.5 note、< 0.5 caution；受體鏈平均 < 70 caution。
- F44 預測與實際受體的逐殘基偏差（`fold_superposition`）：整體 Cα RMSD ≤ 2 Å good、> 2 Å caution；結合位（胜肽 10 Å 內）RMSD 同門檻；偏差 > 3 Å 的殘基在結合位 → caution，否則 note。
- F45 胜肽與受體接觸圖（`fold_contacts`）：4 Å 內算接觸；≥ 50 % 胜肽殘基接觸 good、25–50 % note、< 25 % caution；接觸 ≥ 3 個胜肽殘基的受體殘基列為熱點；最短距離 < 1.5 Å caution。

**膜**
- F46 面積與厚度（`membrane_equil`）：後半段平均在參考值 ±6 %（面積）、±0.3 nm（厚度）內 good，否則 caution；後半段面積漂移 > ±2 % caution；含蛋白時面積只看平台（note）；沒有參考值 note。
- F47 密度剖面（`membrane_density`）：膜中心 |z| < 0.5 nm 的水 < 水相 1 % good，否則 caution；兩個磷峰距離（note）；溶質平均 |z| 在磷峰外 0.5 nm 以上＝水中、±0.5 nm＝頭基區、內側 0.5 nm 以上＝插入。
- F48 序參數（`membrane_scd`）：碳 4–10 平台 −S_CD 0.12–0.25 good；0.25–0.3 note；> 0.3 或 < 0.12 caution。
- F49 插入深度（`insertion_depth`）：後半段質心在磷平面上方 > 0.5 nm＝水中（note）；上方 0.5 到下方 0.3 nm＝表面吸附（good）；下方 0.3–1.0 nm＝介面（note）；≥ 1.0 nm＝疏水核心（note）；開始到後半段變化 > 0.5 nm note；穿過膜中心 caution。
- F50 頭基接觸與停留（`headgroup_residence`）：≥ 50 % 為錨點（good，列出離胺酸、精胺酸）；沒有 → note（短暫）；最後一幀仍接觸者停留時間為下限。
- F51 胜肽傾角（`peptide_tilt`）：≥ 60° 平躺、30–60° 斜插、< 30° 直立（note）；標準差 > 20° caution。
- F52 厚度圖（`thickness_map`）：最薄格 < 平均 80 % caution；格間差 > 0.5 nm note；≤ 0.5 nm good。

**長時間模擬**
- F53 規劃與實際（`longrun_plan`）：完成 ≥ 規劃 99 % good，否則 caution；硬碟 ≤ 規劃每份 125 % good，否則 note；實際天數 > 估計 1.5 倍 note；只存溶質 note。
- F54 前後半段 RMSF（`convergence_rmsf`）：r ≥ 0.8 且平均差 ≤ 0.3 Å good；r ≥ 0.6 note；其他 caution；後半段平均高 > 0.3 Å note。
- F55 前後半段 RMSD 分佈（`convergence_rmsd`）：重疊係數 ≥ 0.6 good、0.3–0.6 note、< 0.3 caution。
- F56 叢集比例隨時間（`cluster_timeline`）：前後兩半各叢集比例差 ≤ 10 個百分點 good，否則 note；前半 < 5 %、最後四分之一 ≥ 20 % 的新叢集 caution。

**粗粒化**
- F57 粗粒化膜性質（`cg_membrane`）：一律先註明粗粒化、珠子層級、不是全原子（note）；面積與厚度同 F46；鍵的 P2 平均 0.1–0.6 good，其他 caution。

**呈現位置**：結案報告（中英文）依章節呈現；系統的「圖表」分頁顯示同一組圖與說明（`report_figures/index.json`）。
所需套件：二級結構、氫鍵、溶劑可及面積、叢集等需要 mdtraj；化合物性質、化學空間與二維作用圖需要 RDKit。缺少時該圖不產生並記錄原因，其餘圖不受影響。
