# 經驗門檻校準（D-144，2026-11-08）

使用者 2026-11-08 要求審閱 D-130／D-135 的經驗門檻。以下是合成資料校準（numpy，腳本內容即本檔下方程式碼摘要），**不是對真實系統的驗證**。

## 1. 重複間 CV > 0.25 的「各條不一致」提醒（`analysis/replica_set.py::CV_DIVERGENT`）
模擬：每條重複的值 ~ N(1, c)，樣本 CV = SD/|mean|，200 000 次。

| 真實 CV | n=3 觸發機率 | n=5 觸發機率 |
|---|---|---|
| 0.10 | 0.3 % | 0.0 % |
| 0.15 | 6.7 % | 3.0 % |
| 0.20 | 22 % | 19 % |
| 0.25 | 37 % | 41 % |
| 0.30 | 50 % | 59 % |
| 0.40 | 67 % | 80 % |

**結論**：n=3 時這是**很弱的偵測器**：真實 CV 0.30 只有一半機率觸發，真實 CV 0.15 有約 7% 誤報。它只能當作「請看各條」的提醒，**不是檢定**，也不能拿「沒觸發」當作各條一致的證據。
門檻維持 0.25（低於它誤報增加很快、高於它幾乎偵測不到）；報告和規格都寫明它是提醒。CV 只用在恆正的比例尺度量（RMSD、Rg、RMSF、接觸數、COM 距離）；差值型量（ΔRMSF、DCCM 元素）不算 CV，改看 CI 與各條同號的 k/n。

## 2. PCA／分群抽樣敏感度（`analysis/extended.py::SENSITIVITY_TOLERANCES`）
模擬：60 維 AR(1) 軌跡 2000 幀，等距抽 250 幀，PC1 特徵值比 λ1/λ2（gap）與自相關時間 τ（幀）可調，每格 60 次。表中為 PC1 |cos| < 0.9 的比例：

| gap | τ | 交錯分半（偶／奇） | 時間前／後半 |
|---|---|---|---|
| 1.1 | 50 | 0.08 | 1.00 |
| 1.5 | 50 | 0.07 | 1.00 |
| 2.0 | 50 | 0.03 | 1.00 |
| 4.0 | 50 | 0.00 | 1.00 |
| 2.0 | 200 | 0.00 | 1.00 |
| 2.0 | 5 | 0.55 | 0.65 |

**結論**：只要軌跡有自相關，**交錯分半幾乎永遠一致**，即使前後半段的主軸完全不同。它只量得到「選哪些幀」的抽樣雜訊，量不到取樣不足。D-135 原本用它決定 `consistent`，**會把取樣不足報成一致**——這是門檻**用錯對象**，不是數值的問題。
**修正**：`pca_sensitivity` 新增 `block_halves`（時間前／後半），`consistent` 改由它和全幀比較決定；交錯分半保留為「抽樣雜訊」並註明不用於判定。`cluster_sensitivity` 同樣改用前／後半的最大族群差。
數值門檻（PC1 |cos| ≥ 0.9、解釋變異差 ≤ 0.10、最大族群差 ≤ 0.15）維持，屬報告用宣告值；前／後半一致仍然**不代表收斂**（兩半可能停在同一個亞穩態）。`common_basis` 本來就同時報 `half_split`（前／後半）與 `interleaved_split`，不受影響。

## 3. 測試
`tests/test_thresholds_calibration.py`：漂移軌跡的交錯分半通過但 `consistent=False`；穩態軌跡 `consistent=True`；分群前後半不同時判不一致；CV 旗標在真實 CV 0.15、n=3 的誤報率落在 4–10%。
