# 水盒：形狀、padding、離子（算力花在哪裡）

狀態：**[已實作・待 CI]**（2026-11-01）。使用者原則：**水盒不應過大，容納整個蛋白即可，不要把算力浪費在水與鹽上。**

## 1. 算力在哪裡
- 顯式溶劑系統 80–90% 的原子是水；PME 成本 ~ N log N。盒子體積就是成本。
- 鹽：0.15 M 在 10k 個水裡約 27 對 Na⁺/Cl⁻ = 54 個原子（< 0.5%）——**鹽不是成本**，但可用 `md.ionic_strength_molar: 0` 只中和。
  不建議：帶電配體與帶電口袋的靜電屏蔽需要生理離子強度，教學／研究 tier 預設保留 0.15 M。

## 2. 決定
| 項目 | 以前 | 現在 | 為什麼 |
|---|---|---|---|
| 形狀 | 立方（OpenMM 以蛋白最長軸決定三邊 → 細長蛋白浪費極大） | **菱形十二面體**（`md.box_shape`，可選 cube/octahedron） | 同樣的「蛋白到影像距離」，體積只有立方的 71%（八面體 77%）。蛋白會旋轉，所以要的是各方向一致的影像距離，不是貼合蛋白形狀的長方盒。 |
| padding | 一律 1.0 nm | **未指定時依 tier**：classroom／teaching 0.8、research 1.0（`TIER_PADDING_NM`）；明寫 `md.padding_nm` 則照用 | 0.8 nm = 2–3 層水，溶劑化殼層完整；截斷半徑 1.0 nm 下蛋白到影像 ≥ 1.6 nm。 |
| 下限 | 無 | **< 0.6 nm → NEEDS_HUMAN**（`MIN_PADDING_NM`） | 再小蛋白就在截斷半徑內看到自己的影像，省下的算力換來錯的結果；真要省請改 `md.solvent: gbn2`。 |
| 篩 pose 的短 MD | 同全流程 | `min(padding, 0.8)` | 只問 pose 會不會散。 |
| 結合計算 | 整盒 padding 提高到 pull + 0.5（最少 1.5） | 不變，但在十二面體裡省 29% | 拉離終點必須離影像夠遠（`binding.py` 的水盒檢查）；十二面體各方向影像距離一致，拉離方向不需特別處理。 |
| 水比例閘門 | < 50% 水 → AUTO_FIXED「可能 padding 不足」 | < 40% → PASS 並說明「緊湊盒子」 | 小盒子是刻意的；影像距離由 padding 保證，不由水比例判斷。 |

決策日誌每次記：形狀、padding、水分子數、體積、「同影像距離的立方盒要多 N% 水」。

## 3. 不做的事
- **長方盒貼合蛋白**：蛋白在 10 ns 內會轉，短邊方向立刻碰到影像；要貼合形狀必須加旋轉約束（改物理）。
- **padding 0**：不是「剛好容納蛋白」，是蛋白與影像直接接觸。
