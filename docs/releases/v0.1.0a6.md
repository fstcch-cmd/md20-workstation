# MD20 v0.1.0a6: Windows and macOS installers (teaching preview)

This version fixes two problems that stopped the interface from opening on Windows. The program itself is the same as v0.1.0a4
(four languages: English, 繁體中文, 日本語, 한국어).

## Fixed
- **"The input line is too long. The syntax of the command is incorrect."** On computers with a long PATH (for example with conda,
  MGLTools or PyMOL installed), the launcher failed before MD20 started. `md20.cmd` and `MD20-GUI.cmd` now start from a short PATH (D-77).
- **The desktop `MD20-GUI.cmd` did nothing.** It was a copy that looked for the program on the desktop. It now calls the installed launcher (D-76).

The release check now double-clicks the desktop launcher with a very long PATH and waits until the interface answers.

## Install
- Windows: download `MD20-Windows-v0.1.0a6.zip`, right-click it, choose "Extract all", then double-click `Install-MD20.cmd`.
  Installing over v0.1.0a4 or v0.1.0a5 is fine; the earlier version is moved to `_to_delete`.
- macOS: download `MD20-macOS-v0.1.0a6.zip`, double-click it in Downloads, then run
  `bash ~/Downloads/MD20-v0.1.0a6/Install-MD20.command` in Terminal. (macOS was not affected.)

Student guides in four languages: `docs/students/`. Known limitations: as in v0.1.0a4 (`docs/archive/releases/v0.1.0a4.md`).
