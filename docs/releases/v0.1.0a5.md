# MD20 v0.1.0a5: Windows and macOS installers (teaching preview)

This version fixes the Windows desktop shortcut. Everything else is the same as v0.1.0a4 (four languages: English, 繁體中文, 日本語, 한국어).

## Fixed
- **Double-clicking `MD20-GUI.cmd` on the Windows desktop did not open the interface.** The installer copied the launcher to the desktop,
  but the copy looked for the program next to itself, on the desktop, and the window closed at once. The desktop launcher now calls the
  installed one in `%LOCALAPPDATA%\MD20` (D-76). The release check now double-clicks the desktop launcher and waits for the interface to answer.

If you installed v0.1.0a4 and do not want to reinstall: open the interface with `%LOCALAPPDATA%\MD20\MD20-GUI.cmd`
(press Win + R, paste the path, press Enter).

## Install
- Windows: download `MD20-Windows-v0.1.0a5.zip`, right-click it, choose "Extract all", then double-click `Install-MD20.cmd`.
- macOS: download `MD20-macOS-v0.1.0a5.zip`, double-click it in Downloads, then run
  `bash ~/Downloads/MD20-v0.1.0a5/Install-MD20.command` in Terminal. (The macOS desktop launcher was not affected.)

Student guides in four languages: `docs/students/`. Known limitations: as in v0.1.0a4 (`docs/archive/releases/v0.1.0a4.md`).
