# MD20 v0.1.0a20：Windows 與 macOS 安裝程式（教學預覽版）

自上一個公開版本 **a17** 以來的累積更新（涵蓋 a18、a19 從未發行的內容）。雙擊 `Install-MD20.cmd`（Windows）或 `Install-MD20.command`（macOS）即可安裝；需約 8 GB 磁碟與網路。

## 介面：看得見、不中斷

- **3D 檢視分頁恢復正常**（D-94）：新版 NiceGUI 會移除內嵌檢視器，導致工作流頁的 3D 分頁空白；改用真正的 iframe，結構與軌跡都能看、能播。建膜時逐步即時顯示每一階段。
- **即時圖表**（D-103）：計算進行中溫度、位能、SMD 拉力/功、進度與 ETA 即時更新；關掉 GUI 計算不中斷、重開接回（計算改為獨立子程序，狀態與進度從檔案讀回）。
- **連線穩定**（D-147）：背景分頁被節流、筆電休眠、Wi-Fi 斷線後，回到前景就立即重連；心跳調整為撐得過大型系統載入時的卡頓。
- **全新視覺設計**（D-146）：以 frontend-design 重做的設計系統，配色、字體、版面一致；閘門狀態用形狀＋顏色（通過／已自動修正／需人工）同時表示，不只靠顏色。
- **流程四階段骨架**（D-153）：工作流步驟表改為【準備→對接→模擬→分析】固定骨架,由上到下＝前到後;未跑到的標「尚未開始」、本案例用不到的標「未使用」。「建模」改名「MD 系統建立」並歸入模擬階段。
- **四種語言**：繁中、英、日、韓全介面與報告文字；每個圖表都有四語標題、判讀指引與結果解釋。

## 圖表可讀性（D-89 系列）

- 圖例一律移到繪圖區右側軸外,絕不蓋住資料、軸或比例尺;時間軸永遠遞增(分段存檔不再把重置畫成時間);每條序列一個顏色、序列多於色盤時改用不同線型,疊圖仍可分辨;密集序列自動不畫標記,折線與標記不互相遮蓋。

## 科學：金屬、結合自由能、重複

- **鋅等金屬鍵結模型**（D-133／D-139／D-145／D-152）：以幾何鍵結模型處理含金屬位點;偵測到金屬旁未配位的帶電羧基(會讓點電荷模型塌陷)時,停下並列出選項(排除非鍵＋平底約束維持晶體距離／確認配位／質子化等),寧可擋也不猜。真實引擎驗證:restrain 後鋅位點不再塌陷。
- **漏斗約束與標準態結合自由能**（D-140／D-151）：教學與研究模式預設以漏斗約束計算可排序的 ΔG°;樣本不足時誠實保留結果並說明,不給不可靠的數字。
- **多重複分析**（D-130／D-131）：平均±標準差、Student-t 信賴區間、重複間一致性;可一鍵補跑重複或傘狀窗口。
- **論文驗證**：內建兩個教學案例——發酵臺灣藜芽代謝物對 NF-κB p65 的多配體同時對接、胜肽對 Keap1——在真實引擎通過重現測試。

## 授權與數位簽章（D-124／D-125）

- 加入以擁有者私鑰 RSA-PSS 簽章的授權機制:真實計算需有效授權;查看、診斷、示範與報告不需授權。驗證端不含任何環境變數／設定／參數後門,私鑰永不進入程式包。

## 安裝與供應鏈

- micromamba、Vina（釘選 v1.2.7）、martini_openmm 等相依皆釘選版本並驗 sha256;安裝程式在乾淨 Windows 與 macOS runner 實際解壓安裝驗證後才發佈。
- 專業版選項:建膜(即時 3D)、胜肽自動摺疊、微秒級長時間模擬、粗粒化 Martini 3。

## 給既有專案

停在任何一步的舊專案,安裝 a20 後按「開始／繼續」即可沿用先前的人工決定接著跑。
