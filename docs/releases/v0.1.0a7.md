# MD20 v0.1.0a7: Windows and macOS installers (teaching preview)

Includes everything in v0.1.0a6 (four languages; Windows launchers fixed for the desktop shortcut and for long PATH settings).

## New: several ligands docked together no longer stop the lesson when every joint pose has touching ligands (D-78)
Docking several ligands into one pocket at classroom search effort often gives joint poses whose ligands touch. Before, the workflow
stopped at "pose selection" and every pose was marked "clash". Now:
- All joint poses are ranked by how safely they can enter molecular dynamics. The order is: other docking objections, whether the
  build's geometry check and a small rigid nudge can clear the contact, ligands that would be dropped as floating, problems left after
  the nudge, ligands that had to be moved, the closest remaining contact, and the score.
- The lowest-risk pose is used automatically and marked in the decision log as a low-risk choice, not a recommendation. You can still
  click another pose in the pose table.
- The usual safety steps still run before MD: the geometry check, the rigid nudge, a soft-core relaxation when needed, and a ring-piercing
  check after minimisation. Only when none of these can untangle the ligands does the run stop and ask which ligand to leave out.
- A failed redocking self-check still stops the run, because then the docking setup itself cannot be trusted.

## Install
- Windows: download `MD20-Windows-v0.1.0a7.zip`, extract it, double-click `Install-MD20.cmd`. Installing over an earlier version is fine.
- macOS: download `MD20-macOS-v0.1.0a7.zip`, double-click it in Downloads, then run
  `bash ~/Downloads/MD20-v0.1.0a7/Install-MD20.command` in Terminal.

Student guides in four languages: `docs/students/`. Known limitations: as in v0.1.0a4 (`docs/archive/releases/v0.1.0a4.md`).
