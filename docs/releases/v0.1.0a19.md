# MD20 v0.1.0a19: Windows and macOS installers (preview)

v0.1.0a18 was prepared but never published; everything listed for it below is released for the first time here.

## Fixed in v0.1.0a19 (D-95): new installs work again
- The installer stopped at `pip install openmmforcefields`: the only release on PyPI (0.15.1) was withdrawn upstream
  for an incomplete dependency list. The installer now asks for exactly that version, which pip still accepts.
  Computers where MD20 is already installed were not affected.

## New in v0.1.0a19 (D-96 to D-98): the report says only what the data supports
- **Binding free energy.** Each result now carries a quality assessment separate from "the run finished". Missing
  checks count as not passed. Ligands are ranked against each other only when every result passed and the conditions
  match; otherwise the report describes them without ranking. Older projects show "not passed (no record)" until the
  binding step is analysed again.
- **Repeats.** The report counts independent MD starting points separately from pulls that share one start; three
  seeds from one MD end point are not three independent repeats.
- **Structure check.** Resolution, R-free or NMR limits are listed as accepted limitations, not as repairs; only
  changes with a recorded difference count as repairs.
- **Interactions.** Salt bridges need opposite charges; a polar pair closer than 3.5 Å is called polar proximity, not a
  hydrogen bond. Every saved frame is searched, so contacts formed late in the run are found, and residues with the
  same number on different chains stay separate. Ligand charges come from the ligand's chemistry (both oxygens of a
  carboxylate count); when they are unknown, no salt bridge is called.
- **Ligand state and persistence.** "Stays bound" now uses contacts, distance from the pocket and RMSD together; each
  interaction gets an event table with interruptions and censoring; no lifetime is given when the save interval or the
  number of events cannot support one.
- **Docking fallback.** When no joint pose passes, MD20 only takes a pose whose problems the build can repair
  (ligands touching each other). Ligands that do not share the pocket, a pocket too small for all of them, or poses
  outside the score window stop the run instead, and the report keeps the original reasons for the pose used.
- **Decision log.** The report lists only decisions of this workflow; the summary keeps every caution.


## Also in this series, first released here (D-93): the exit-path card always has something you can press
- Ligands touching the pulled ligand from the side no longer count as blocking its way out (this is what stopped
  hsieh2024 URI). Only atoms the ligand would move closer to count.
- Molecular dynamics only now really skips binding free energy, also for ligands added after the report.
- New buttons when a way out is still blocked: Compute it bound alone (an extra MD with only this ligand; the shared-pocket
  MD is kept), and Choose anchor residues (type residue numbers such as 120, 145, A:163) to change the pulling direction.
  The card explains why "pull the outer ligand first" is not offered.
- The page waits up to 3 minutes for the calculation instead of showing "connection lost" while a large system loads.
- Projects that stopped at this point: install a19 and press Start or continue.

## Also first released here (D-94): the 3D view tab works again
- On the workflow page the 3D view tab was empty with the current NiceGUI (it removed the embedded viewer). It now
  shows the structure and plays the trajectory. The 3D view inside the report was not affected.

## Earlier in this series (D-92): a blocked exit path is solved automatically
- In the all-ligands system, the default pulling direction can run through another ligand. MD20 now looks for an exit
  that crosses no other ligand and the fewest protein atoms, moves the anchor behind the ligand on that line, and
  records the angle and the reason. Only if every way out is blocked does it stop, and then the card has a button:
  leave this ligand out and compute the others.
- Projects that stopped at this point: press Start or continue; the new exit is found and the calculation goes on.

## Also in this series (D-91)
- Double-clicking `Install-MD20.cmd` inside the zip, without extracting it, used to fail with a PowerShell error
  ("-File ... install.ps1 does not exist"). It now stops with a short message in Chinese and English: extract the zip
  first, then run `Install-MD20.cmd` from the extracted folder.

## Also in this series (D-89): line charts redrawn
- The time axis of MD figures was wrong when a run was saved in several files (every file restarted at 0, so one curve
  jumped back to the start again and again and looked like many lines). Time now comes from the simulation record.
  For projects analysed with an older version, open the workflow and press Rebuild the report; no MD needs to be rerun.
- The key is always outside the plot on the right; every line is named with the ligand name you typed; each series keeps
  one colour in the whole report; more than three series are drawn one panel each; thin lines are every saved frame and
  thick lines a running mean, both explained in the key.

## Earlier in this series (D-87): binding free energy per ligand, also after the report; saved work found again
- Choose which ligands get SMD and umbrella sampling, also in the all-ligands system (for example teaching mode 1,
  hsieh2024). The pulled ligand leaves while the others stay in the pocket; the report labels it "with the other ligands".
- After the report, open Binding free energy on the workflow page to add another ligand or one more SMD run of a finished one.
  Finished targets are kept; the report combines every run (each run listed, then the mean and its error).
  Rebuild the report from the same panel at any time.
- The home page lists every workflow saved in Documents/MD20_Projects, newest first, with search, the report mark and
  whether a run was interrupted. Open one and press Start or continue to go on.

## Earlier in this series (D-88): you choose where projects are saved
- Projects folder on the home page: paste a path or Browse…, then Save projects here (for example a drive with more space).
  MD20 and the command line use that folder next time.
- Open this project or workflow: open a project or workflow folder from anywhere (for example one a classmate gave you).
- Recent folders are listed for switching back.

## Earlier in this series (D-86): coarse-grained Martini 3 runs from start to report
- Professional mode, Membrane group: set Resolution to Coarse-grained Martini 3. Systems: a membrane protein in a bilayer
  (orientation from the hydrophobic belt), a peptide on a membrane surface, a bilayer alone, or a protein in water.
- One install: press Install now in the coarse-grained row of the Computer status page, or run `md20 setup-cg --yes`.
  It installs martinize2, insane and martini_openmm and downloads the Martini 3 force-field files (checked by SHA-256).
- The run: minimisation, NVT, NPT with the membrane barostat, then 20 fs production in resumable chunks. The report shows
  area per lipid, PO4–PO4 thickness, tail order, backbone-bead RMSD and membrane contacts, all labelled bead-level.
- No docking, no binding free energy, no small molecules in coarse-grained systems. Not yet measured on a laptop GPU.

## Earlier in this series (D-85): paste a peptide sequence, folding happens on its own
- In quick mode, paste the sequence into the ligand box, for example `MEL GIGAVLKVLTTGLPALISWIKRKRQQ`, or the sequence alone.
  `peptide:` is no longer needed. A sequence made only of C, N, P, S, F and I could also be SMILES, so it stops and asks.
- Peptides of 10 or more residues are ticked "Fold this peptide first" by default: the structure is predicted, then docked and simulated.
- Install the folding tool once: double-click `Install-Folding.cmd` (macOS `Install-Folding.command`) in the unzipped folder, or press
  Install now on the Computer status page. It downloads several GB (20 to 60 minutes) and folds one test peptide so the weights are in place
  before class. `Install-MD20.cmd -WithFold` does both installs in one go.
- Not yet checked on a laptop: the folding install and GPU prediction on Windows, and anything on macOS.

Includes everything in v0.1.0a8. v0.1.0a17 also fixes four problems found on the Windows laptop check (D-83), and `md20 setup-cg` now finds martinize2 even when its command is not on PATH (D-84). New in professional mode (D-80 to D-82). These features are new: the code is tested in CI where noted,
and the laptop checks are listed in `docs/STATUS.md`. Treat their results as preliminary.

## New
- **Fold a peptide from its sequence.** `md20 fold <sequence>` or the "fold this peptide" box in quick mode. OmegaFold for a peptide alone,
  Boltz-2 for a receptor and peptide together, or upload a structure from AlphaFold Server or ColabFold. The confidence (pLDDT, ipTM) is a gate:
  low confidence is labelled or stops the run with options. A predicted complex can go straight to molecular dynamics after the predicted receptor
  is superposed on the real one. The folding tools are an optional install of several GB: `md20 setup-fold --engine omegafold --yes`
  (installed in its own environment so the main one is not changed).
- **Membranes.** A membrane protein in a bilayer (orientation found from the hydrophobic belt), a peptide or molecule on the membrane surface
  (no crossing), or a bilayer alone. POPC, POPE, DLPC, DLPE, DMPC, DOPC lipids; the membrane barostat; area per lipid, thickness, density
  profile, order parameters, insertion depth, contact residues and residence time, tilt. Mixed bacterial membranes with cardiolipin are not
  available yet and stop with an explanation.
- **Long runs.** Up to 10 µs in professional mode. Runs over 100 ns get a plan (days, disk, save interval, solute-only trajectory); over 1 µs
  needs your confirmation. Long trajectories are analysed in chunks. Coarse-grained Martini 3 tools can be installed with `md20 setup-cg --yes`.
- **Report**: new figures and sections for folding, membranes, long runs and coarse-grained runs, in four languages.

## Install
- Windows: `MD20-Windows-v0.1.0a19.zip` → extract → double-click `Install-MD20.cmd`.
- macOS: `MD20-macOS-v0.1.0a19.zip` → double-click in Downloads → `bash ~/Downloads/MD20-v0.1.0a19/Install-MD20.command` in Terminal.

Student guides: `docs/students/`. Specifications: `docs/specs/membrane.md`, `structure_prediction.md`, `long_timescale.md`,
`master_iteration_2026-11-07.md`.
