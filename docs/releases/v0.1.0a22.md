# v0.1.0a22（教學預覽版，Windows 與 macOS）

2026-11-09 prerelease。取代 a21。

## 重點
- **內建擁有者正式公鑰（D-169）**：由 HCC Lab 正式私鑰簽發的授權檔可正常驗證。a20／a21 以前請升級到 a22。私鑰不在任何 repo。
- **放寬 OpenMM 相依，支援更多顯卡驅動（D-172）**：先前把 OpenMM 鎖死在 8.6.1 會要求很新的 NVIDIA 驅動（CUDA ≥12.9）。a22 改用範圍 `openmm>=8.5,<8.7`，讓安裝器依你的驅動自動挑對應的 CUDA 建置——**CUDA 12.x 的驅動不必更新就能用 GPU**。
- **安裝器更穩**：CUDA 環境若解不出來，會自動退回 OpenCL/CPU 重試，不再中途崩潰（D-172）。
- 簽發端 `MD20-Signer`（私人 repo）啟動器強制使用 Python 3（D-162）。

## 其他
