# MD20 v0.1.0a8: Windows and macOS installers (teaching preview)

Includes everything in v0.1.0a7 (four languages, Windows launcher fixes, and the lowest-risk joint pose when all joint poses clash).

## Fixed: the example compound table for high-throughput screening (D-79)
The example Excel file mixed six ways of naming a compound. Two of them could not work as uploaded: one row pointed to a file
`my_compound.sdf` that does not exist, and the others needed downloads from PubChem, ChEMBL or the PDB. A screen stops when rows fail,
so uploading the example as is got stuck. The example now has eight compounds written as SMILES (four benzamidine-type trypsin inhibitors
and four controls for the 3PTB case), which runs without a network. A second sheet explains the other columns with one example each.

## Install
- Windows: download `MD20-Windows-v0.1.0a8.zip`, extract it, double-click `Install-MD20.cmd`. Installing over an earlier version is fine.
- macOS: download `MD20-macOS-v0.1.0a8.zip`, double-click it in Downloads, then run
  `bash ~/Downloads/MD20-v0.1.0a8/Install-MD20.command` in Terminal.

Student guides in four languages: `docs/students/`. Earlier notes: `docs/archive/releases/`.
