# MD20 v0.1.0a2 — Windows 安裝程式（教學預覽版，修正 NVIDIA 安裝失敗）

**v0.1.0a1 在有 NVIDIA 顯示卡的電腦上會安裝失敗**（`ocl-icd-system ... does not exist`，D-36）；請改用本版。沒有 NVIDIA 卡（OpenCL／CPU）的電腦不受影響。

安裝方式與 v0.1.0a1 相同：下載 **`MD20-Windows-v0.1.0a2.zip`** → 解壓 → 雙擊 `Install-MD20.cmd`。
已裝過 v0.1.0a1 或安裝中斷：直接執行本版安裝程式即可（`%LOCALAPPDATA%\MD20\app` 會被新版取代，環境會補齊）。

## 變更
- `environment/windows-cuda.yml` 移除 Windows 上不存在的 `ocl-icd-system`（D-36）。
- CI 與發行流程新增「CUDA 環境可解（cuda-version 12.4 與 11.8，dry run）」檢查：runner 沒有 NVIDIA GPU，之前從未走過 CUDA 安裝路徑。
- `installer/MD20-SelfTest.cmd`：筆電一鍵自測（安裝 → doctor → demo → GUI → classroom 3PTB），完整 log（D-35）。

其餘說明與已知限制見 `docs/releases/v0.1.0a1.md` 與 `docs/STATUS.md`。
