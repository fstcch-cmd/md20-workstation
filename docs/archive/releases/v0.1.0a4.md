# MD20 v0.1.0a4: Windows and macOS installers (teaching preview)

This version adds Japanese and Korean, and rewrites the interface, report and student-guide text so it reads more plainly.
Everything else works as in v0.1.0a3.

## Install
- Windows: download `MD20-Windows-v0.1.0a4.zip`, right-click it, choose "Extract all", then double-click `Install-MD20.cmd`.
  An earlier version is not deleted. It is moved to `_to_delete`.
- macOS: download `MD20-macOS-v0.1.0a4.zip`, double-click it in Downloads, then run
  `bash ~/Downloads/MD20-v0.1.0a4/Install-MD20.command` in Terminal.

Step-by-step guides for students, in four languages: `docs/students/WINDOWS.md` and `docs/students/MAC.md` (Traditional Chinese),
plus `.en.md`, `.ja.md` and `.ko.md` versions next to them.

## What changed
- **Four languages.** The language menu at the top right offers English, 繁體中文, 日本語 and 한국어. The interface, the teaching pages,
  the parameter advice, the gate explanations, the computer status page and the project report all follow it (D-74).
  The decision log keeps its reasons in Chinese, as recorded. The command line stays in Chinese.
- **Switching language never interrupts a calculation.** CI starts a lesson in the real interface, switches through all four
  languages while it runs, leaves and reopens the page and presses the start button again. The run must start once, keep going and
  stay a single workflow (`tools/gui_preview.py`).
- **Plainer wording** in the interface, teaching material, report and student guides. Numbers, thresholds and scientific checks did not change.
  The style rules are in `docs/specs/writing_style.md`.
- The methods paragraph of the report is written in a style you can paste into a thesis, in each language.

## Known limitations
- The Japanese and Korean text has not yet been checked by native speakers.
- The limitations listed for v0.1.0a3 still apply. In particular, one-dimensional centre-of-mass free-energy profiles strongly overestimate
  binding for buried ligands, so compare ligands by trend only.
- The Vina thread fix for Windows hybrid CPUs (D-72) has not been confirmed on the laptop yet.

Full status: `docs/STATUS.md`. Decisions: `docs/DECISIONS.md` (D-74).
