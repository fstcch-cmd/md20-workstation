# MD20 v0.1.0a1 — Windows 安裝程式（教學預覽版）

HCC Lab, NKUST。Docking → 建模 → OpenMM MD → SMD／傘狀採樣的單機教學版。**預覽版**：流程完整、閘門會擋下不確定的情況，但仍在驗證中（見下方「已知限制」）。

## 安裝（約 15–30 分鐘，多半在下載）
1. 下載下方的 **`MD20-Windows-v0.1.0a1.zip`**，按右鍵「解壓縮全部」。
2. 進入解壓出的資料夾，**雙擊 `Install-MD20.cmd`**（不需要 git，也不需要 PowerShell 7）。
   - 若 Windows 跳出 SmartScreen 安全提示，選「其他資訊」→「仍要執行」（腳本未簽章）。
   - 程式會裝到 `%LOCALAPPDATA%\MD20`（約 6 GB，需 ≥ 8 GB 可用空間）；要裝到別的磁碟：在該資料夾開命令列執行 `Install-MD20.cmd -Root D:\MD20`。
   - 有 NVIDIA 驅動（`nvidia-smi` 可用）自動走 CUDA，否則 OpenCL；驅動太舊會自動改 OpenCL 並提示。
3. 完成後桌面會出現 **`MD20-GUI.cmd`**，雙擊即開啟瀏覽器介面（http://127.0.0.1:8020，只有本機能連）。
   解壓的資料夾之後可以刪除（程式已複製到 `%LOCALAPPDATA%\MD20\app`）。

接下來的步驟（確認 GPU、demo、第一個真實案例、篩選、回報）見 repo 的 `docs/WINDOWS_QUICKSTART.md`。

## 這一版驗證過什麼（CI，commit bb36a4b 起）
- Windows（OpenCL，CPU runner）367 項測試通過；跳過的 5 項只是在別的 CI job 跑（重型／論文）或缺 playwright。
- **本 ZIP 本身**在乾淨的 Windows 上以 Windows PowerShell 5.1 解壓、安裝，刪除解壓資料夾後 `doctor`／`demo`／`pipeline example` 仍可執行，才會發行。
- Ubuntu／macOS 同樣通過；3PTB 全流程（含結合自由能）、短 MD 篩 pose、金屬鍵結模型、論文對接重現在 Ubuntu 通過。

## 已知限制（誠實版）
- **GPU 實機路徑（CUDA／OpenCL on GPU）只在使用者筆電驗證**，CI runner 沒有 GPU。請把 `md20.cmd doctor` 的平台與 ns/day 回報。
- 隱式溶劑 GBn2 只有在 GPU 上才明顯較快；純 CPU 筆電請用預設的顯式水。
- 金屬（鋅）幾何鍵結模型的平均鍵長偏差接近 0.3 Å 容許上限，力常數表待改進；金屬位點的結果請當定性參考。
- 1D COM 距離的 ΔG° 只是近似（報告會標註）；胜肽配體的結合自由能只給定性比較。
- 3D 檢視器在 headless 瀏覽器的繪圖測試尚未自動化。
