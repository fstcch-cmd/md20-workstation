# MD20 ライセンスの入手と取り込み

MD20 のソースコードは公開されていますが、実際の計算（ドッキング、系の構築、分子動力学、結合自由エネルギー、ペプチドの折りたたみ）には HCC Lab が署名したライセンスファイルが必要です。ライセンスがなくても、パソコンの診断（`doctor`）、デモ（`demo`）、レポートの閲覧、グラフィカルインターフェースは使えます。

## 1. マシンコードを確認する
1. インストールが終わったら、デスクトップの `MD20-Unlock.cmd` をダブルクリックします（Mac は `MD20-Unlock.command`）。
2. ウィンドウの一番上の行が、このパソコンのマシンコードです。`3F9A-07C2-B15D-6E48` のような形をしています。クリップボードにもコピーされます。
3. マシンコードを先生に送ってください。先生は、このパソコンだけで使えるライセンスに署名します。
4. コマンドラインで `%LOCALAPPDATA%\MD20\md20.cmd license machine` と入力しても表示できます。インターフェースの各ページ上部にある「MD20 のライセンスが必要です」のカードにも表示されます。

## 2. ライセンスファイルを取り込む
先生から、拡張子が `.md20license` のファイルが届きます。次のどれかで取り込みます。
- **ドラッグ＆ドロップ**：ファイルをデスクトップの `MD20-Unlock.cmd` のアイコンにドラッグします。
- **ダブルクリック**：`MD20-Unlock.cmd` をダブルクリックし、開いたウィンドウでファイルを選びます。
- **グラフィカルインターフェース**：ページ上部のカードで「ライセンスファイルを取り込む」を押し、ファイルを選びます。

「ライセンスをインストールしました」と表示されれば完了です。期限が切れるまで、ほかの操作は要りません。

## 3. よく出るメッセージ
| メッセージ | 意味 | 対処 |
|---|---|---|
| このパソコンにはまだ MD20 のライセンスがない | まだ取り込んでいません | 上の手順で入手して取り込む |
| このライセンスは別のパソコンに紐づいている | ほかの人のファイルです | このパソコンのマシンコードを先生に送り、署名し直してもらう |
| ライセンスの期限が切れている | 期限を過ぎています | 先生に更新を頼み、新しいファイルを取り込む |
| ライセンスファイルの署名が正しくない | ファイルが改変または破損しています | もう一度ファイルをもらう。テキストエディタで開いたり保存したりしない |

ライセンスファイルは個人用です。他の人に渡したり、公開の場所に置いたりしないでください。MD20 が作るファイルには、ライセンス番号と名前が記録され、あとから追跡できます。

コマンドラインでは、`md20 license status` で状態を確認し、`md20 license install ファイル名` で取り込みます。ライセンスがないと、計算コマンドは終了コード 13 で止まり、理由を表示します。
