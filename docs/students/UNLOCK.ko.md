# MD20 라이선스 받기와 가져오기

MD20의 소스 코드는 공개되어 있지만, 실제 계산(도킹, 계 구축, 분자동역학, 결합 자유 에너지, 펩타이드 접힘)에는 HCC Lab이 서명한 라이선스 파일이 필요합니다. 라이선스가 없어도 컴퓨터 점검(`doctor`), 데모(`demo`), 보고서 보기, 그래픽 인터페이스는 그대로 쓸 수 있습니다.

## 1. 머신 코드 확인
1. 설치가 끝나면 바탕화면의 `MD20-Unlock.cmd`를 더블클릭합니다(Mac은 `MD20-Unlock.command`).
2. 창의 맨 윗줄이 이 컴퓨터의 머신 코드입니다. `3F9A-07C2-B15D-6E48` 같은 모양이며 클립보드에도 복사됩니다.
3. 머신 코드를 교수님께 보내십시오. 교수님이 이 컴퓨터에서만 쓸 수 있는 라이선스에 서명합니다.
4. 명령줄에서 `%LOCALAPPDATA%\MD20\md20.cmd license machine`을 입력해도 됩니다. 그래픽 인터페이스 각 페이지 위쪽의 'MD20 라이선스가 필요합니다' 카드에도 표시됩니다.

## 2. 라이선스 파일 가져오기
교수님이 확장자가 `.md20license`인 파일을 보내 줍니다. 아래 중 하나로 가져옵니다.
- **끌어다 놓기**: 파일을 바탕화면의 `MD20-Unlock.cmd` 아이콘 위로 끌어다 놓습니다.
- **더블클릭**: `MD20-Unlock.cmd`를 더블클릭하고, 열린 창에서 파일을 고릅니다.
- **그래픽 인터페이스**: 페이지 위쪽 카드에서 '라이선스 파일 가져오기'를 누르고 파일을 고릅니다.

'라이선스를 설치했습니다'가 보이면 끝입니다. 만료일까지 따로 할 일은 없습니다.

## 3. 자주 나오는 메시지
| 메시지 | 뜻 | 할 일 |
|---|---|---|
| 이 컴퓨터에는 아직 MD20 라이선스가 없습니다 | 아직 가져오지 않았습니다 | 위 순서대로 받아서 가져오기 |
| 이 라이선스는 다른 컴퓨터에 묶여 있습니다 | 다른 사람의 파일입니다 | 이 컴퓨터의 머신 코드를 교수님께 보내 다시 서명받기 |
| 라이선스가 만료되었습니다 | 기한이 지났습니다 | 교수님께 갱신을 요청하고 새 파일을 가져오기 |
| 라이선스 파일의 서명이 올바르지 않습니다 | 파일이 바뀌었거나 손상되었습니다 | 파일을 다시 받기. 텍스트 편집기로 열거나 저장하지 마십시오 |

라이선스 파일은 개인용입니다. 다른 사람에게 넘기거나 공개된 곳에 올리지 마십시오. MD20이 만드는 파일에는 라이선스 번호와 이름이 기록되어 나중에 추적할 수 있습니다.

명령줄에서는 `md20 license status`로 상태를 보고 `md20 license install 파일명`으로 가져옵니다. 라이선스가 없으면 계산 명령은 종료 코드 13으로 멈추고 이유를 알려 줍니다.
