# MD20 학생용 사용 안내: macOS

macOS 12 이상(Apple Silicon M1–M4 또는 Intel), 8 GB 이상의 여유 디스크 공간, 인터넷 연결이 필요합니다. Mac에는 CUDA가 없으므로 OpenCL 또는 CPU로 계산합니다. NVIDIA 노트북보다 느립니다. **수업 사례에는 classroom 등급을 사용하십시오.**

## 1. 설치(처음 한 번만, 약 15–30분)
1. `MD20-macOS-v0.1.0a19.zip`을 내려받고 "다운로드" 폴더에서 더블클릭해 압축을 풉니다. `MD20-v0.1.0a19` 폴더가 생깁니다.
2. "터미널"을 열고(Launchpad에서 Terminal 검색), 아래 줄을 붙여 넣은 뒤 Enter를 누릅니다.

```
bash ~/Downloads/MD20-v0.1.0a19/Install-MD20.command
```
   - 마지막에 "完成 Done."이 나타나면 설치가 끝난 것입니다. 오류가 나오면 터미널의 글자를 복사해 선생님께 보내 주십시오.
   - 프로그램은 홈 폴더의 `MD20` 폴더에 설치됩니다. 내려받은 폴더는 나중에 지워도 됩니다.
3. 바탕 화면에 `MD20-GUI.command`가 생깁니다.

## 2. 사용할 때마다
- 그래픽 화면: 바탕 화면의 `MD20-GUI.command`를 더블클릭한 뒤 브라우저에서 http://127.0.0.1:8020 을 엽니다. 계산 중에는 **터미널 창을 닫지 마십시오**. 브라우저는 닫아도 됩니다. 다 쓰고 나서 터미널 창을 닫습니다.
- 처음에 "열 수 없습니다"라는 메시지가 나오면 파일을 마우스 오른쪽 버튼으로 클릭하고 "열기"를 고른 뒤 다시 "열기"를 누릅니다.
- 화면 언어: 오른쪽 위의 언어 메뉴에서 English, 繁體中文, 日本語, 한국어를 바꿀 수 있습니다.
- 계산하면서 보고서를 쓰고 싶을 때: 오른쪽 위의 자원 메뉴는 평소 "균형(기본)"으로 되어 있습니다. "절약: 보고서를 쓰면서 사용"으로 바꾸십시오. 다음 계산 단계부터 적용됩니다. 컴퓨터를 쓰지 않을 때는 "최대 속도: 컴퓨터를 쓰지 않을 때"를 고를 수 있습니다.
- 명령줄: 터미널에 아래 줄을 입력합니다.

```
~/MD20/md20 doctor
```
명령줄 출력은 중국어입니다. "選用 OpenMM 平台"(사용하는 OpenMM 플랫폼) 줄을 보십시오. OpenCL이면 그래픽 칩을 쓰고 있는 것입니다. CPU로도 실행되지만 느립니다.

```
~/MD20/md20 demo
```
실제 계산을 하지 않는 시연용 워크플로입니다. 1분 안에 끝나고 보고서를 만듭니다. 끝까지 실행되면 설치는 정상입니다.

## 3. 첫 번째 실제 사례(트립신과 벤즈아미딘)
```
cd ~/Desktop
~/MD20/md20 pipeline example > trypsin.json
sed -i '' 's/"tier": "teaching"/"tier": "classroom"/' trypsin.json
~/MD20/md20 pipeline run trypsin.json --project first_case
```
- 세 번째 줄은 등급을 classroom(2 ns)으로 바꿉니다. Mac에서는 2–4시간 정도 걸릴 것으로 추정합니다. 아직 실측하지 않았습니다.
- 프로젝트 이름에는 영문자와 숫자만 사용하십시오.
- 노트북은 **전원에 연결하고** 잠자기 상태가 되지 않게 하십시오.
- 중간에 터미널을 닫아도 괜찮습니다. **마지막 줄을 다시 입력하면 멈춘 곳부터 이어서 계산합니다.**
- 결과는 "문서" 폴더 안의 `MD20_Projects/first_case`에 있습니다. 그 안의 `report.html`을 여십시오.

## 4. 예전 워크플로로 돌아가기, 결합 자유 에너지 리간드 고르기
- **닫았다 열어도 찾을 수 있습니다**: `MD20-GUI.command`를 다시 실행하면 홈의 '최근 워크플로'에 '문서/MD20_Projects'에 저장된 모든 워크플로가 최신순으로 나오고 검색도 됩니다. '미완료, 이어서 가능'이나 '지난번 중단'으로 표시된 것은 열어서 '시작 또는 계속'을 누르면 멈춘 곳부터 이어서 진행합니다. 완료된 것은 보고서를 열 수 있습니다.
- **저장 위치를 직접 정하고 어떤 프로젝트 폴더든 열기**: 홈의 '프로젝트 폴더'에서 경로를 붙여 넣거나 '찾아보기…'로 고릅니다. '여기에 저장'을 누르면 새 프로젝트가 그곳(예: 공간이 넉넉한 외장 드라이브)에 저장되고, 다음에 MD20과 명령줄을 쓸 때도 같은 폴더를 씁니다. 다른 사람에게 받은 프로젝트 폴더(또는 워크플로 폴더)는 골라서 '이 프로젝트 또는 워크플로 열기'를 누르면 바로 열립니다. 최근 사용한 폴더는 아래에 나오며 클릭하면 돌아갈 수 있습니다.
- **모든 리간드 계(예: 교육 모드 1, hsieh2024)에서도 하나를 골라 SMD**: 워크플로 페이지에서 '결합 자유 에너지(SMD와 우산 샘플링)'를 열고 리간드 하나를 선택한 뒤 '선택한 리간드 계산'을 누릅니다. 당길 때 다른 리간드는 포켓에 남으며, 보고서에는 '다른 리간드와 공존'으로 표시되고 단독 결합과 직접 비교할 수 없습니다.
- **보고서 뒤에도 추가할 수 있습니다**: 같은 곳에서 다른 리간드를 선택하고 '선택한 리간드 계산'을 누릅니다. 이미 계산한 것은 다시 계산하지 않습니다. 같은 리간드를 새 난수 시드로 한 번 더 계산하려면 그것을 선택하고 '선택한 리간드 SMD 한 번 더'를 누릅니다. 보고서에 회차별 결과와 평균이 나옵니다.
- 합쳐진 보고서를 바로 보려면 '보고서 다시 만들기'를 누릅니다. 리간드 하나에 SMD와 우산 샘플링으로 몇 시간이 걸리므로 전원을 연결한 뒤 누르십시오.

## 5. 펩타이드를 리간드로 쓰기(서열 붙여 넣기)
1. **먼저 접힘 도구를 설치합니다(처음 한 번만, 수업 전에 집에서)**: 압축을 푼 폴더의 `Install-Folding.command`을 더블클릭합니다. PyTorch와 모델 가중치를 합쳐 수 GB를 내려받으며 약 20~60분 걸리고, 마지막에 펩타이드 하나를 시험으로 접습니다. 마지막에 Done이 나오면 설치된 것입니다. 화면의 '컴퓨터 상태' 페이지에서 '지금 설치'를 눌러도 됩니다.
2. 빠른 모드의 리간드 칸에 이름을 앞에 쓰고 서열을 붙여 넣습니다.
   ```
   MEL GIGAVLKVLTTGLPALISWIKRKRQQ
   ```
   서열만 써도 됩니다. 이름은 PEP가 됩니다. 이제 `peptide:`는 필요 없습니다.
3. 10잔기 이상의 펩타이드는 '이 펩타이드를 먼저 접기'가 자동으로 체크됩니다. 구조를 예측한 뒤 도킹과 MD를 진행합니다. 접지 않으려면 체크를 해제합니다. 10잔기보다 짧은 펩타이드는 혼자서는 정해진 구조가 없는 경우가 많아 접지 않고, 도킹에서 형태를 바꿉니다.
4. 예측 신뢰도가 낮거나(pLDDT 50 미만) 접힘 도구가 없으면 '접힘' 단계에서 멈추고 할 수 있는 일을 보여 줍니다. 도구 설치, AlphaFold Server 구조 업로드, 접지 않기 중에서 고릅니다.
5. 서열이 C, N, P, S, F, I 글자로만 이루어져 있으면(예: `CCCCCN`) SMILES로도 읽히므로, 앞에 `peptide:` 또는 `smiles:`를 붙이라고 안내합니다.

## 6. 조립화 Martini 3(전문 모드, 선택)
마이크로초 이상 걸리는 현상(막단백질이 막 안에 놓이는 모습, 펩타이드가 막에 붙는 과정, 막 자체의 변화)을 볼 때 씁니다. 중원자 약 4개를 비드 하나로 묶고 시간 간격이 20 fs라서 같은 노트북으로 전원자보다 수십 배 길게 계산합니다.
1. **먼저 도구를 설치합니다(처음 한 번만)**: 화면의 '컴퓨터 상태' 페이지에서 조립화 도구 줄의 '지금 설치'를 누르거나 `~/MD20/md20 setup-cg --yes`를 실행합니다. martinize2, insane, martini_openmm을 설치하고 Martini 3 역장 파일도 내려받은 뒤 완료 메시지를 보여 줍니다.
2. 전문 모드의 '막 계' 그룹에서 '해상도'를 '조립화 Martini 3'으로 바꾸고 계 종류를 고릅니다. 막단백질(PDB ID 입력), 막 표면 접촉(리간드 칸에 펩타이드 서열), 막만, 막 없음(물 속 단백질)입니다.
3. 길이는 평소의 본 계산 길이 설정을 따릅니다. 1 µs를 넘으면 먼저 확인을 요청합니다.
4. 조립화에서는 도킹과 결합 자유 에너지를 하지 않고 저분자 리간드는 계에 넣지 않습니다. 보고서의 값은 비드 단위이며 전원자 결과가 아니고, 보고서에도 그렇게 적힙니다.

## 7. 문제가 생겼을 때
아래 줄을 실행하고 출력을 복사해 선생님께 보내 주십시오.
```
~/MD20/md20 doctor --no-benchmark
```
