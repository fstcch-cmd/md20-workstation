# MD20 学生向け操作ガイド：macOS

macOS 12 以降（Apple Silicon の M1–M4 または Intel）、8 GB 以上の空きディスク容量、インターネット接続が必要です。Mac には CUDA がないため、OpenCL または CPU で計算します。NVIDIA 搭載のノートパソコンより遅くなります。**授業の課題では classroom 等級を使ってください。**

## 1. インストール（最初の一回だけ、約 15–30 分）
1. `MD20-macOS-v0.1.0a9.zip` をダウンロードし、「ダウンロード」の中でダブルクリックして展開します。`MD20-v0.1.0a9` というフォルダーができます。
2. 「ターミナル」を開き（Launchpad で Terminal を検索します）、次の行を貼り付けて Enter を押します。

```
bash ~/Downloads/MD20-v0.1.0a9/Install-MD20.command
```
   - 最後に「完成 Done.」と表示されたらインストール完了です。エラーが出たら、ターミナルの文字をコピーして先生に送ってください。
   - プログラムはホームフォルダーの `MD20` フォルダーに入ります。ダウンロードしたフォルダーは後で削除してかまいません。
3. デスクトップに `MD20-GUI.command` ができます。

## 2. 毎回の使い方
- 画面操作：デスクトップの `MD20-GUI.command` をダブルクリックし、ブラウザーで http://127.0.0.1:8020 を開きます。計算中は**ターミナルのウィンドウを閉じないでください**。ブラウザーは閉じてもかまいません。使い終わったらターミナルのウィンドウを閉じます。
- 初回に「開けません」と表示されたら、ファイルを右クリックして「開く」を選び、もう一度「開く」を押します。
- 表示言語：右上の言語メニューで English、繁體中文、日本語、한국어 を切り替えられます。
- 計算しながらレポートを書きたいとき：右上のリソースメニューは普段「バランス（既定）」になっています。「省リソース：レポートを書きながら使う」に変えてください。次の計算ステップから反映されます。パソコンを使わないときは「フル稼働：パソコンを使っていないとき」を選べます。
- コマンドライン：ターミナルで次の行を入力します。

```
~/MD20/md20 doctor
```
コマンドラインの出力は中国語です。「選用 OpenMM 平台」（使用する OpenMM プラットフォーム）の行を見てください。OpenCL ならグラフィックチップを使っています。CPU でも動きますが、遅くなります。

```
~/MD20/md20 demo
```
実際の計算をしないデモのワークフローです。1 分以内に終わり、レポートを作ります。最後まで終われば、インストールは正常です。

## 3. 最初の実例（トリプシンとベンズアミジン）
```
cd ~/Desktop
~/MD20/md20 pipeline example > trypsin.json
sed -i '' 's/"tier": "teaching"/"tier": "classroom"/' trypsin.json
~/MD20/md20 pipeline run trypsin.json --project first_case
```
- 3 行目で等級を classroom（2 ns）に変えます。Mac では 2–4 時間ほどかかる見込みです。まだ実測はしていません。
- プロジェクト名には英字と数字だけを使ってください。
- ノートパソコンは**電源につなぎ**、スリープさせないでください。
- 途中でターミナルを閉じてもかまいません。**最後の行をもう一度入力すれば、止まったところから続きます。**
- 結果は「書類」フォルダーの中の `MD20_Projects/first_case` にあります。その中の `report.html` を開いてください。

## 4. うまくいかないとき
次の行を実行し、出力をコピーして先生に送ってください。
```
~/MD20/md20 doctor --no-benchmark
```
