# 取得與匯入 MD20 授權

MD20 的原始碼是公開的，但真正的計算（對接、建模、分子動力學、結合自由能、胜肽摺疊）需要 HCC Lab 簽發的授權檔。沒有授權時，電腦狀態（`doctor`）、示範（`demo`）、查看報告和開啟圖形介面都照常可用。

## 1. 取得機器碼
1. 安裝完成後，雙擊桌面的 `MD20-Unlock.cmd`（Mac 是 `MD20-Unlock.command`）。
2. 視窗最上面一行是這台電腦的機器碼，長得像 `3F9A-07C2-B15D-6E48`。程式已經把它複製到剪貼簿。
3. 把機器碼傳給老師。老師會用它簽一份只能在你這台電腦使用的授權檔。
4. 也可以在命令列輸入 `%LOCALAPPDATA%\MD20\md20.cmd license machine`。圖形介面每一頁上方的「需要 MD20 授權」卡片也會顯示機器碼。

## 2. 匯入授權檔
老師會給你一個副檔名是 `.md20license` 的檔案。三種方法擇一：
- **拖放**：把檔案拖到桌面的 `MD20-Unlock.cmd` 圖示上。
- **雙擊**：雙擊 `MD20-Unlock.cmd`，在跳出的視窗選這個檔案。
- **圖形介面**：在頁面上方的卡片按「匯入授權檔」，選這個檔案。

看到「授權已安裝」就完成了。之後不用再做任何事，直到授權期限到。

## 3. 常見訊息
| 訊息 | 意思 | 怎麼辦 |
|---|---|---|
| 這台電腦還沒有 MD20 授權 | 還沒匯入 | 照上面取得並匯入 |
| 這份授權綁定其他電腦 | 這是別人的授權檔 | 把這台電腦的機器碼傳給老師，請他重簽 |
| 授權已過期 | 超過期限 | 向老師申請續期，收到新檔後再匯入一次 |
| 授權檔的簽章不正確 | 檔案被改過或損毀 | 重新向老師要一份，不要用文字編輯器開啟或存檔 |

授權檔是你個人的。不要轉給別人，也不要放在公開的地方。MD20 產生的檔案會記錄授權編號和你的姓名，方便追溯。

命令列的指令：`md20 license status`（看狀態）、`md20 license install 檔名`（匯入）。沒有授權時，計算指令會以結束碼 13 停止並說明原因。
