# MD20 學生操作說明：macOS

你需要 macOS 12 以上（Apple Silicon M1–M4 或 Intel 都可以）、至少 8 GB 的可用磁碟空間，以及網路。Mac 沒有 CUDA，程式會用 OpenCL 或 CPU 計算，速度比 NVIDIA 筆電慢。**課堂案例請用 classroom 等級。**

## 1. 安裝（只做一次，約 15–30 分鐘）
1. 下載 `MD20-macOS-v0.1.0a15.zip`，在「下載項目」裡雙擊解壓縮，會得到資料夾 `MD20-v0.1.0a15`。
2. 打開「終端機」（在 Launchpad 搜尋 Terminal），貼上下面這行，按 Enter。

```
bash ~/Downloads/MD20-v0.1.0a15/Install-MD20.command
```
   - 最後出現「完成 Done.」才算裝好。如果出現錯誤，把終端機裡的文字複製給老師。
   - 程式會裝在家目錄的 `MD20` 資料夾。下載的那個資料夾之後可以刪掉。
3. 裝好後，桌面會多一個 `MD20-GUI.command`。

## 2. 每次使用
- 圖形介面：雙擊桌面的 `MD20-GUI.command`，再用瀏覽器打開 http://127.0.0.1:8020 。計算進行時，**不要關掉那個終端機視窗**。瀏覽器可以關，用完再把終端機視窗關掉。
- 第一次如果出現「無法打開」，在檔案上按右鍵，選「打開」，再按一次「打開」。
- 介面語言：右上角的語言選單可以切換 English、繁體中文、日本語、한국어。
- 想一邊計算一邊寫報告：右上角的資源選單平常顯示「平衡（預設）」，改選「省資源：可同時寫報告」。從下一個計算步驟開始生效。電腦沒有要用的時候，可以選「全速：電腦閒置時」。
- 命令列：在終端機輸入下面這行。

```
~/MD20/md20 doctor
```
找「選用 OpenMM 平台」這一行。寫 OpenCL 表示有用到顯示晶片。寫 CPU 也能跑，只是比較慢。

```
~/MD20/md20 demo
```
這是不做真正計算的示範流程，1 分鐘內會跑完並產生報告。跑得完就表示安裝正常。

## 3. 第一個真實案例（胰蛋白酶與苯甲脒）
```
cd ~/Desktop
~/MD20/md20 pipeline example > trypsin.json
sed -i '' 's/"tier": "teaching"/"tier": "classroom"/' trypsin.json
~/MD20/md20 pipeline run trypsin.json --project first_case
```
- 第三行把等級改成 classroom（2 ns）。在 Mac 上估計要 2–4 小時，還沒有實測過。
- 專案名稱只用英文字母和數字。
- 筆電要**接上電源**，也不要讓它進入睡眠。
- 中途關掉終端機沒關係，**再打一次最後一行，會從中斷的地方繼續**。
- 結果在「文件」資料夾裡的 `MD20_Projects/first_case`，打開裡面的 `report.html`。

## 4. 回到舊專案、選配體做結合自由能
- **關掉再打開也找得到**：重新雙擊 `MD20-GUI.command` 後，首頁「最近的流程」會列出「文件/MD20_Projects」裡所有存過的流程，最新的在上面，可以搜尋。標「未完成，可以繼續」或「上次中斷」的，點進去按「開始或繼續」就從中斷處接著跑；已完成的可以開報告。
- **自己決定存放位置、打開任何專案資料夾**：首頁「專案資料夾」可以貼上路徑或按「瀏覽…」選資料夾。按「存到這個資料夾」之後，新專案都存在那裡（例如空間較大的 外接硬碟），下次打開 MD20、以及命令列，也會用同一個資料夾。拿到別人的專案資料夾（或某個流程資料夾），選它按「開啟這個專案或流程」就能直接打開。最近用過的資料夾會列在下面，點一下就能切回去。
- **多配體（例如教學模式一 hsieh2024）也能指定一個配體做 SMD**：流程頁打開「結合自由能（SMD＋傘狀採樣）」，勾一個配體，按「計算選取的配體」。拉這個配體時，其他配體留在口袋裡，報告會標為「與其他配體共存」，數值不能和單獨結合直接比。
- **報告做完後還能加做**：同一個地方再勾別的配體按「計算選取的配體」；已經算完的不會重算。想讓同一個配體多做一次（新的亂數種子），勾它按「選取的配體再做一次 SMD」，報告會列出每一次的結果和平均。
- 要立刻看整合後的報告，按「重新整理報告」。每個配體的 SMD＋傘狀採樣要幾小時，接上電源再按。

## 5. 胜肽當配體（直接貼序列）
1. **先裝摺疊工具（只做一次，上課前在家裝）**：雙擊解壓資料夾裡的 `Install-Folding.command`。它會下載 PyTorch 和模型權重，共數 GB，約 20–60 分鐘，最後會試摺一個胜肽。最後看到 Done 就裝好了。也可以在介面的「電腦狀態」頁按「一鍵安裝」。
2. 在快速模式的配體欄，直接貼上序列，名稱寫在前面：
   ```
   MEL GIGAVLKVLTTGLPALISWIKRKRQQ
   ```
   只貼序列也可以，名稱會自動取為 PEP。不用再加 `peptide:`。
3. 10 個殘基以上的胜肽，旁邊的「先摺疊這個胜肽」會自動勾起：程式先預測結構，再對接、跑 MD。不想摺疊就取消勾選。少於 10 個殘基的胜肽單獨存在時通常沒有固定結構，不摺疊，直接由對接改變構形。
4. 預測信心太低（pLDDT 低於 50）或沒有裝摺疊工具時，流程會停在「摺疊」，並列出可以怎麼做：安裝工具、上傳 AlphaFold Server 的結構，或不摺疊。
5. 序列只由 C、N、P、S、F、I 這幾個字母組成時（例如 `CCCCCN`），它也可能是 SMILES，程式會請你在前面加 `peptide:` 或 `smiles:`。

## 6. 粗粒化 Martini 3（專業模式，選用）
想看微秒以上的現象（膜蛋白在膜裡的排列、胜肽貼上膜、膜本身的變化）時用粗粒化。約 4 個重原子併成一顆珠子，時間步 20 fs，同一台筆電可以跑到全原子的數十倍長。
1. **先裝工具（只做一次）**：在介面的「電腦狀態」頁，粗粒化工具那一列按「一鍵安裝」，或在命令列執行 `~/MD20/md20 setup-cg --yes`。會安裝 martinize2、insane、martini_openmm，並下載 Martini 3 力場檔，最後顯示「安裝完成」。
2. 專業模式的「膜系統」群組：「模擬解析度」選「粗粒化 Martini 3」，再選膜系統類型：膜蛋白（輸入 PDB 編號）、膜表面接觸（配體欄貼胜肽序列）、純膜，或不用膜（蛋白在水中）。
3. 模擬長度照一般的「正式模擬長度」設定；超過 1 µs 要先勾確認。
4. 粗粒化不做對接，也不算結合自由能；小分子配體不會放進系統。報告的數值是珠子層級，不是全原子結果，報告會標註。

## 7. 出問題時
執行下面這行，把輸出複製給老師。
```
~/MD20/md20 doctor --no-benchmark
```
