# MD20 학생용 사용 안내: Windows

Windows 10 또는 11, 8 GB 이상의 여유 디스크 공간, 인터넷 연결이 필요합니다. NVIDIA 그래픽카드가 있으면 자동으로 GPU(CUDA)로 계산합니다. NVIDIA 그래픽카드가 없어도 OpenCL 또는 CPU로 실행되지만 느립니다.

## 1. 설치(처음 한 번만, 약 15–30분)
1. 선생님이 알려 준 다운로드 페이지에서 `MD20-Windows-v0.1.0a11.zip`을 내려받습니다.
2. 파일을 마우스 오른쪽 버튼으로 클릭하고 "모두 압축 풀기"를 선택합니다.
3. 압축을 푼 폴더를 열고 `Install-MD20.cmd`를 더블클릭합니다.
   - 파란색 "Windows의 PC 보호" 창이 나타나면 "추가 정보"를 누른 다음 "실행"을 누릅니다.
   - 창 마지막에 "完成"(완료)이 나타나면 설치가 끝난 것입니다. 오류가 나오면 창 전체의 글자를 사진으로 찍어 선생님께 보내 주십시오.
4. 바탕 화면에 `MD20-GUI.cmd`가 생깁니다.

## 2. 사용할 때마다
- 그래픽 화면: 바탕 화면의 `MD20-GUI.cmd`를 더블클릭하면 브라우저에서 http://127.0.0.1:8020 이 열립니다. 계산 중에는 **검은 창을 닫지 마십시오**. 브라우저는 닫아도 됩니다. 다 쓰고 나서 검은 창을 닫습니다.
- 화면 언어: 오른쪽 위의 언어 메뉴에서 English, 繁體中文, 日本語, 한국어를 바꿀 수 있습니다.
- 계산하면서 보고서를 쓰고 싶을 때: 오른쪽 위의 자원 메뉴는 평소 "균형(기본)"으로 되어 있습니다. "절약: 보고서를 쓰면서 사용"으로 바꾸십시오. 다음 계산 단계부터 적용됩니다. 컴퓨터를 쓰지 않을 때는 "최대 속도: 컴퓨터를 쓰지 않을 때"를 고를 수 있습니다.
- 명령줄: `Win + R`을 누르고 `cmd`를 입력한 뒤 Enter를 누르고, 아래 줄을 입력합니다.

```
%LOCALAPPDATA%\MD20\md20.cmd doctor
```
명령줄 출력은 중국어입니다. "選用 OpenMM 平台"(사용하는 OpenMM 플랫폼) 줄을 보십시오. CUDA나 OpenCL이면 그래픽카드를 쓰고 있는 것입니다. CPU이면 쓰지 않는 것입니다. 그래도 실행은 되지만 느립니다.

```
%LOCALAPPDATA%\MD20\md20.cmd demo
```
실제 계산을 하지 않는 시연용 워크플로입니다. 1분 안에 끝나고 보고서를 만듭니다. 끝까지 실행되면 설치는 정상입니다.

## 3. 첫 번째 실제 사례(트립신과 벤즈아미딘)
```
cd %USERPROFILE%\Desktop
%LOCALAPPDATA%\MD20\md20.cmd pipeline example > trypsin.json
notepad trypsin.json
%LOCALAPPDATA%\MD20\md20.cmd pipeline run trypsin.json --project first_case
```
- 세 번째 줄을 실행하면 메모장이 열립니다. `"tier": "teaching"`을 `"tier": "classroom"`(2 ns)으로 바꾸고 저장한 뒤 메모장을 닫습니다.
- RTX 4060 노트북에서 classroom은 실측 76.5분이었습니다. 바꾸지 않고 teaching(10 ns)으로 두면 약 3시간이 걸릴 것으로 추정합니다. NVIDIA 그래픽카드가 없으면 훨씬 느리므로 classroom을 사용하십시오.
- 프로젝트 이름에는 영문자와 숫자만 사용하십시오. 한글이나 중국어 이름을 쓰면 폴더 이름이 알아볼 수 없는 코드로 바뀝니다.
- 노트북은 **전원에 연결하십시오**. 배터리로 쓰면 계산이 자동으로 일시 정지됩니다.
- 중간에 창을 닫아도 괜찮습니다. **마지막 줄을 다시 입력하면 멈춘 곳부터 이어서 계산합니다.**
- 결과는 "문서" 폴더 안의 `MD20_Projects\first_case`에 있습니다. 그 안의 `report.html`을 여십시오.

## 4. 문제가 생겼을 때
아래 줄을 실행하고 출력을 사진으로 찍거나 복사해 선생님께 보내 주십시오.
```
%LOCALAPPDATA%\MD20\md20.cmd doctor --no-benchmark
```
