# MD20 学生向け操作ガイド：Windows

Windows 10 または 11、8 GB 以上の空きディスク容量、インターネット接続が必要です。NVIDIA のグラフィックカードがあれば、自動的に GPU（CUDA）で計算します。NVIDIA のカードがなくても OpenCL または CPU で動きますが、遅くなります。

## 1. インストール（最初の一回だけ、約 15–30 分）
1. 先生から案内されたダウンロードページで `MD20-Windows-v0.1.0a14.zip` をダウンロードします。
2. ファイルを右クリックして「すべて展開」を選びます。
3. 展開されたフォルダーを開き、`Install-MD20.cmd` をダブルクリックします。
   - 青い「Windows によって PC が保護されました」が出たら、「詳細情報」を押してから「実行」を押します。
   - ウィンドウの最後に「完成」（完了）と表示されたらインストール完了です。エラーが出たら、ウィンドウ全体の文字を写真に撮って先生に送ってください。
4. デスクトップに `MD20-GUI.cmd` ができます。

## 2. 毎回の使い方
- 画面操作：デスクトップの `MD20-GUI.cmd` をダブルクリックすると、ブラウザーで http://127.0.0.1:8020 が開きます。計算中は**黒いウィンドウを閉じないでください**。ブラウザーは閉じてもかまいません。使い終わったら黒いウィンドウを閉じます。
- 表示言語：右上の言語メニューで English、繁體中文、日本語、한국어 を切り替えられます。
- 計算しながらレポートを書きたいとき：右上のリソースメニューは普段「バランス（既定）」になっています。「省リソース：レポートを書きながら使う」に変えてください。次の計算ステップから反映されます。パソコンを使わないときは「フル稼働：パソコンを使っていないとき」を選べます。
- コマンドライン：`Win + R` を押し、`cmd` と入力して Enter を押してから、次の行を入力します。

```
%LOCALAPPDATA%\MD20\md20.cmd doctor
```
コマンドラインの出力は中国語です。「選用 OpenMM 平台」（使用する OpenMM プラットフォーム）の行を見てください。CUDA か OpenCL ならグラフィックカードを使っています。CPU なら使っていません。それでも動きますが、遅くなります。

```
%LOCALAPPDATA%\MD20\md20.cmd demo
```
実際の計算をしないデモのワークフローです。1 分以内に終わり、レポートを作ります。最後まで終われば、インストールは正常です。

## 3. 最初の実例（トリプシンとベンズアミジン）
```
cd %USERPROFILE%\Desktop
%LOCALAPPDATA%\MD20\md20.cmd pipeline example > trypsin.json
notepad trypsin.json
%LOCALAPPDATA%\MD20\md20.cmd pipeline run trypsin.json --project first_case
```
- 3 行目でメモ帳が開きます。`"tier": "teaching"` を `"tier": "classroom"`（2 ns）に書き換え、保存してメモ帳を閉じます。
- RTX 4060 搭載のノートパソコンでは、classroom は実測 76.5 分でした。書き換えずに teaching（10 ns）のままだと、約 3 時間かかる見込みです。NVIDIA のカードがないとかなり遅くなるので、classroom を使ってください。
- プロジェクト名には英字と数字だけを使ってください。中国語や日本語の名前にすると、フォルダー名が読めない記号の列になります。
- ノートパソコンは**電源につないでください**。バッテリー駆動のときは計算が自動的に一時停止します。
- 途中でウィンドウを閉じてもかまいません。**最後の行をもう一度入力すれば、止まったところから続きます。**
- 結果は「ドキュメント」フォルダーの中の `MD20_Projects\first_case` にあります。その中の `report.html` を開いてください。

## 4. 前のワークフローに戻る、結合自由エネルギーのリガンドを選ぶ
- **閉じても見つかる**：`MD20-GUI.cmd` をもう一度起動すると、ホームの「最近のワークフロー」に「ドキュメント\MD20_Projects」に保存したすべてのワークフローが新しい順に並び、検索もできます。「未完了、続けられます」や「前回中断」と出ているものは、開いて「開始または再開」を押すと中断したところから続きます。完了したものはレポートを開けます。
- **保存先を自分で決める、どのプロジェクトのフォルダーでも開ける**：ホームの「プロジェクトのフォルダー」でパスを貼り付けるか「参照…」で選びます。「ここに保存する」を押すと、新しいプロジェクトはそこに保存され（空きの多い D ドライブなど）、次に MD20 やコマンドラインを使うときも同じフォルダーを使います。ほかの人からもらったプロジェクトのフォルダー（またはワークフローのフォルダー）は、選んで「このプロジェクト／ワークフローを開く」を押すとそのまま開けます。最近使ったフォルダーは下に並び、クリックすると戻れます。
- **全リガンドの系（例：教育用モード 1、hsieh2024）でも 1 つを選んで SMD**：ワークフローのページで「結合自由エネルギー（SMD と傘サンプリング）」を開き、リガンドを 1 つチェックして「選んだリガンドを計算」を押します。引き離すとき、ほかのリガンドはポケットに残ります。レポートでは「ほかのリガンドと共存」と表示され、単独の結合とは直接比べられません。
- **レポートの後でも追加できます**：同じ場所で別のリガンドにチェックを入れて「選んだリガンドを計算」を押します。計算済みのものはやり直しません。同じリガンドをもう 1 回（新しい乱数の種で）計算するには、それを選んで「選んだリガンドの SMD をもう 1 回」を押します。レポートには各回の結果と平均が出ます。
- まとめたレポートをすぐ見るには「レポートを作り直す」を押します。リガンド 1 つにつき SMD と傘サンプリングで数時間かかるので、電源につないでから押してください。

## 5. ペプチドをリガンドにする（配列を貼り付ける）
1. **先に折りたたみツールを入れる（最初の一回だけ、授業前に自宅で）**：展開したフォルダーの `Install-Folding.cmd` をダブルクリックします。PyTorch とモデルの重みを合わせて数 GB ダウンロードし、20〜60 分ほどかかります。最後にペプチドを一つ試しに折りたたみます。最後に Done と出ればインストールできています。画面の「パソコンの状態」ページで「今すぐインストール」を押しても入れられます。
2. クイックモードのリガンド欄に、名前を前に付けて配列を貼り付けます。
   ```
   MEL GIGAVLKVLTTGLPALISWIKRKRQQ
   ```
   配列だけでも構いません。名前は PEP になります。`peptide:` はもう要りません。
3. 10 残基以上のペプチドは「このペプチドを先に折りたたむ」に自動でチェックが入ります。構造を予測してから、ドッキングと MD を行います。折りたたまない場合はチェックを外します。10 残基より短いペプチドは単独では決まった構造を持たないことが多いので折りたたまず、ドッキングで形を変えます。
4. 予測の信頼度が低い（pLDDT が 50 未満）とき、または折りたたみツールがないときは、「折りたたみ」で止まり、できることを示します。ツールのインストール、AlphaFold Server の構造のアップロード、折りたたまない、のいずれかです。
5. 配列が C、N、P、S、F、I の文字だけでできているとき（例：`CCCCCN`）は SMILES とも読めるので、前に `peptide:` か `smiles:` を付けるよう求められます。

## 6. 粗視化 Martini 3（プロモード、任意）
マイクロ秒以上かかる現象（膜タンパク質の膜内での配置、ペプチドが膜に付く過程、膜そのものの変化）を見るときに使います。重原子およそ 4 個を 1 個のビーズにまとめ、時間刻みは 20 fs なので、同じノート PC で全原子の数十倍の長さを計算できます。
1. **先にツールを入れる（最初の一回だけ）**：画面の「パソコンの状態」ページで、粗視化ツールの行の「今すぐインストール」を押すか、`%LOCALAPPDATA%\MD20\md20.cmd setup-cg --yes` を実行します。martinize2、insane、martini_openmm を入れ、Martini 3 の力場ファイルもダウンロードし、最後に完了のメッセージが出ます。
2. プロモードの「膜系」グループで「分解能」を「粗視化 Martini 3」にし、系の種類を選びます。膜タンパク質（PDB ID を入力）、膜表面への接触（リガンド欄にペプチド配列）、膜のみ、膜なし（水中のタンパク質）です。
3. 長さはふだんの本計算の長さの設定に従います。1 µs を超えると先に確認を求めます。
4. 粗視化ではドッキングと結合自由エネルギーを行わず、低分子リガンドは系に入れません。レポートの値はビーズ単位で全原子の結果ではなく、レポートにもそう書かれます。

## 7. うまくいかないとき
次の行を実行し、出力を写真に撮るかコピーして先生に送ってください。
```
%LOCALAPPDATA%\MD20\md20.cmd doctor --no-benchmark
```
