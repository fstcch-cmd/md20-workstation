教學 tier 在 GTX 1060 級筆電（約 200 ns/day 水盒基準）上，一個蛋白–配體系統的 10 ns 約 2–4 小時；純 CPU 筆電建議 classroom tier 並排夜間佇列（`md20 queue run --hours 22-7`）。

學生安裝與第一個案例照 `docs/students/WINDOWS.md`、`docs/students/MAC.md`；專案名稱請用英數字。
學生邊算邊寫報告時，介面右上角的資源選單改選**省資源：可同時寫報告**（約 ¼ CPU、GPU 50%）；整夜計算選**全速：電腦閒置時**。變更從下一個計算步驟起生效。

## 圖形介面的教學模式（v0.1.0a3 起）

首頁有四種模式：**教學模式一（多種小分子，hsieh2024）**、**教學模式二（胜肽，hsieh2025）**、快速模式、專業模式。
教學頁依序呈現論文出處、研究背景、學習目標、本案例示範的科學檢查、流程與每一步的學習重點、本教學使用的參數（含理由；論文明確給出的設定會標示「依論文設定」）與討論題；
按「開始這個教學案例」即以快速模式參數建立流程。對接與姿勢選擇完成後流程會停下詢問是否進入分子動力學，適合在課堂上先討論姿勢再繼續。
介面與報告可切換英文（預設）與繁體中文；報告每節依序為「這一步是什麼、科學意義、使用的參數、圖表、結果解釋」，可直接作為作業繳交。

## 內建驗證／教學案例（HCC Lab 論文）

用 `md20 validate <case>` 產生設定檔，再 `md20 pipeline run <file>` 跑完整流程。兩個案例刻意各自示範一個常見錯誤，正好對應 MD20 的閘門。

| 案例 | 論文 | 標的 (PDB) | 配體 | 示範重點 |
|---|---|---|---|---|
| `hsieh2024` | J. Ethnopharmacol. 318 (2024) 116980 | NF-κB RELA/p65 | 六個水萃代謝物（多配體同時對接） | 論文標註 1VKF，但 1VKF 其實是 *Thermotoga* 甘油操縱子蛋白；MD20 以座標比對判定正解為 **1VKX**（結構可信度閘門） |
| `hsieh2025` | LWT 222 (2025) 117641 | Keap1-BTB (4CXT) | 胜肽 GRP = GGGGGKP | 胞內標靶但胜肽淨電荷僅 +1，**CPP 科學限制提醒**（不擋流程）並提出替代設計；論文的搜尋區 36×51×45 Å 等同盲對接，**活性位可及性**提醒；論文稱的「covalent bonding」其實是凡得瓦接觸 |

課堂搜尋強度：教學模式一（hsieh2024，六個代謝物同時對接）在 classroom／teaching 等級用 **exhaustiveness 8**，research 等級才用論文的 32——
筆電上 32 跑了 3 小時以上仍未完成（D-71）。8 是課堂可行性的取捨，聯合姿勢的分數較不穩定；報告會標明實際使用的值。

重點：這些案例的目的不是「重現論文數字」（exhaustiveness、質子化、亂數種子未公開，無法逐位重現），而是示範**先把科學假設與結構品質把關做好，再談對接分數**。

### CPP（穿膜胜肽）無法通過時

對胞內標靶，若胜肽依序列特徵預測無法穿膜，MD20 會標註為**科學限制**（科學假設問題，不是計算設定問題；流程照常進行，因為使用者的標靶未必在胞內），同時提出三類具體替代設計，並以同一啟發式評分排序：

1. **縮短為帶電核心**：去掉 Gly 填充，保留帶電殘基（如 GGGGGKP → `GKP`、`KP`）。
2. **富集 Arg/Lys**：把填充 Gly 換成 K/R，使淨電荷 ≥ +3（如 `GGGKKKP`）。
3. **接穿膜載體**：N 端融合 TAT／R8／penetratin。

報告並列出外部 CPP 預測工具（BIOPEP-UWM、CellPPD、CPPpred、MLCPP 2.0）供交叉確認——內建評分只是初篩，不能取代實驗或外部預測。流程不會因此停止；報告與介面會保留這段科學限制說明（D-48）。

### 胜肽到不了活性位時

胜肽比藥物小分子大且柔軟，Vina 一定會給出 pose，但最常見的失敗是停在活性位旁的表面。MD20 在對接前比較胜肽大小與搜尋區，pose 選定後計算埋藏比例與距活性位距離；不合格時提醒「表面貼附／沒到活性位」並建議改選 pose 或縮小搜尋區。對酵素抑制研究這代表抑制機制的推論不成立；研究表面結合時可以忽略。
